# ボード・記事・返信を読む

## ボードを選ぶ

`BOARDS` で利用可能なボードを表示し、`BOARD 番号` または選択画面の番号で移動します。親子階層、表示順、振り分け専用のMENUノードがあります。`INFO` / `I` で現在ボードの説明と長文案内を確認します。共通パスワードがあるボードでは非表示入力で解除します。親の権限・パスワードも適用されます。

`L` / `NOTES` は親記事の一覧、`TREE 記事番号` は返信の木です。番号指定で本文を読みます。非表示・取り消し・権限のない記事は通常の本文表示の対象になりません。

## 読書中の操作

| 操作 | 動作 |
|---|---|
| Enter / CONTINUE | 次の記事 |
| P | 前の記事 |
| L | 同じ本文の再表示 |
| D / PARENT | 親記事 |
| A / CHILD | 返信側へ |
| TREE | 返信ツリー |
| R | この本文への返信を作成 |
| G / GET | 本文を共通編集バッファへ取り込む |
| S | 投稿者プロフィールを表示して読書へ戻る |
| K | 権限があれば取り消しの確認へ |
| E | 権限に応じた題名・投稿者の変更 |
| + / -、+N / -N | 方向切替・相対移動 |
| F | 次から無停止連続表示。入力で停止 |
| 0 | 一覧へ戻る |

検索・連続読書では、その時点の範囲、投稿者、検索語を保持して移動します。プロフィールを見ても記事番号や読書条件を失いません。`S` で会員プロフィールを表示できないゲスト投稿者などもあります。

**読むだけでは記事を既読にしません。** `SEEN` で明示的に既読へ変更します。メールを読んだときの既読処理とは異なります。[未読管理](article-search.md)を参照してください。

## 題名変更と取り消し

`RETITLE 記事番号 題名` は本人、管理者、担当SIGOPが権限に従って実行します。本文を書き換える操作ではありません。`WITHDRAW 番号` は確認、`WITHDRAW 番号 CONFIRM` は取り消しです。本人に加え、全体管理者と親から継承した担当SIGOPも実行できます。

取り消しは復元できませんが、記事番号・返信関係・操作履歴は残ります。本文の物理回収は外部管理ツールで別に行います。管理者の `HIDE`（非表示）と `RESTORE`（再表示）は取り消しとは別です。

`G` / `GET` は閲覧権限だけで本文を共通バッファへコピーし、新規投稿を開始しません。後で[エディタ](editor.md)の `/BUFFER` から利用します。共通バッファの保存先にも本文が残る点に注意してください。

## 次期版の取り消し・子孫記事の表示（未リリース）

0.74.1の公開済み配布物からの変更です。通常ボード・共有ボードの両方で、親記事をWITHDRAWまたはHIDEすると、その子・孫以降も通常閲覧できなくなります。子孫自身の取り消し記録は作らず、記事番号、本文、親子関係を保持します。一覧・ツリー・検索・未読/新着・前後移動・返信先選択・共通バッファへの取り込みに同じ判定を使います。返信数・最新記事・未読件数にも不可視の子孫を含めません。

HIDE解除後は、その記事・祖先が取り消し済みでなく、他の非表示がなければ再表示できます。WITHDRAWは不可逆です。共有記事の権限は[共有ボード](links.md)を参照してください。
