# 会員間メールと添付

## 読む・返信する

`MAIL` でメール画面へ進み、Lで一覧、番号で読書、Eで宛先・題名から作成、R番号で返信、K番号で削除確認、0で戻ります。`MAIL INBOX` / `SENT` / `UNREAD` で絞り、`MAIL NEXT` は次の未読、`MAIL LATEST` は最新1通です。

本文表示中はEnterで次、Pで前、Lで再表示、Fで無停止連続表示、+/-や+N/-Nで方向・相対移動。`MAIL LIST` で一覧に戻ります。`MAIL SCAN ASC` / `DESC` も使えます。G / `MAIL GET [番号]` は共通編集バッファへ取り込みます。

メールは送受信者だけが扱えます。受信者が読むと既読になります。`MAIL SEARCH 語句` は本人の送受信メールの題名・本文を検索し、英字の大小を区別します。`MAIL NEWS 日付` と `CHECK MAIL` は[新着検索](article-search.md)を参照してください。

削除は送信者・受信者のいずれも実行でき、両者から削除されます。`MAIL DELETE 番号` の確認内容を読んで確定してください。`MAIL NOTIFY ON` / `OFF` で新着通知を会員ごとに保存します。

## 作成と下書き

`MAIL SEND ログイン名 題名`、`MAIL REPLY 番号` も使用できます。本文編集と確定は[エディタ](editor.md)と共通です。`/SAVE` で保存、`MAIL DRAFT` で版確認、`MAIL RESUME` で再開します。

`SYSOPMAIL 題名` はゲストからも利用でき、設定済み管理者のうち会員番号が最小の有効会員へ送信します。管理者の設定が必要です。宛先不明の公開伝言にはGatherを使います。

## 添付する

1通最大16ファイル、1ファイル最大1GiB、合計最大16GiBです。設置者が小さい上限を設定している場合はそちらが適用されます。

端末では `ZMAILUPLOAD [説明]` または `ZMAILUPLOADBATCH 説明` で非公開添付領域へアップロードし、`MAIL FILES` で番号を確認します。編集中に `/ATTACH 番号` を繰り返し、`/DETACH 番号` で1件、`/DETACH` で全部を外します。同じ番号を重複して添付しません。下書きでも添付参照を保持します。

WebUIではメール作成画面でファイルを選び、送信または下書き保存時にアップロードします。添付番号の手入力は不要です。保存済みの下書き添付は名前で確認できます。

`ZMAILDOWNLOAD ファイル番号` は単体取得、`ZMAILDOWNLOADALL メール番号` はそのメールの一括取得です。同名ファイルには番号を前置して区別します。Zを付けない `MAILUPLOAD` / `MAILUPLOADBATCH` / `MAILDOWNLOAD` / `MAILDOWNLOADALL` はPROTOCOLで選んだ方式です。XMODEM・TEXTは単体のみで、アップロードに `名前|サイズ|説明` を指定します。

中断した単体は `ZMAILRESUME 元の説明`、一括は `ZMAILRESUMEBATCH 説明`。元と同じファイル・内容・説明で再開してください。[転送と再開](transfers.md)も参照します。

## 添付の公開範囲と回収

添付は送信者と受信者だけが取得できます。**SYSOPにも私信を読む例外はありません。** 最後のメール・下書き参照を削除すると容量を回収します。未使用の本人ファイルは `MAIL DROP 番号 CONFIRM` で回収できます。公開保管庫のファイル番号と混同しないでください。
