# 管理者・SIGOPと権限

## 権限の種類

全体管理者は `admins.conf` に数値の会員IDを明記します。ログイン名がsysopであることや会員レベル5だけでは管理者になりません。会員レベルは0〜5、グループは1〜100です。

掲示板SIGOPとファイル保管庫SIGOPは別の担当指定です。親の担当権限を子孫に継承します。`SIGOPS` で担当一覧を確認します。閲覧・投稿のACL、共通パスワード、会員の有効状態もそれぞれ確認されます。

| 操作 | 本人 | SIGOP | 全体管理者 |
|---|---|---|---|
| 記事取り消し・題名変更 | 自分の記事 | 担当と子孫 | 全体 |
| 記事の非表示・復元・投稿者変更 | 不可 | 担当と子孫 | 全体 |
| 子ボード新設・設定・下位担当指定 | 不可 | 担当配下、自己昇格不可 | 全体 |
| 会員グループ追加・除外 | 不可 | 担当ボードのACLグループまたは委任範囲 | 全体 |
| 会員レベル変更・停止・削除 | 自分の退会は別操作 | 不可 | 全体 |
| 記事移動・ボード削除 | 不可 | 不可 | 全体 |
| 私信・添付の閲覧 | 送受信者 | 権限による例外なし | 権限による例外なし |
| 任意接続の切断・停止予告 | 不可 | 不可 | 全体 |

SIGOPの親変更は移動元・移動先の両方を担当する範囲だけです。自身の担当元を書き換えて権限を増やしたり、担当外を取り込んだりできません。保護された管理者会員へのSIGOPによるグループ変更も拒否します。

`SIGOPGROUP ボード番号 グループ番号` は追加の担当グループ委任です。現在担当ボードの閲覧・投稿条件にあるグループについては、この追加指定なしでも会員追加・除外が可能です。`GROUPMOVE` と `BOARDGROUP` の違いは[ボード管理](board-admin.md)を参照してください。

管理メニュー・管理HELPは権限に応じて表示します。Web側のフォーム表示に加えて、本体が毎回権限を検査します。権限変更・パスワード変更によって既存接続が失効する場合があります。
