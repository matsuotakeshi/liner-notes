# プロフィールと個人設定

## プロフィール

`PROFILE` は自分、`PROFILE ログイン名` は相手、`PROFILES [検索語]` は一覧・検索です。`+` で続き、番号で詳細を表示します。利用停止会員は通常一覧に表示しません。

| 項目 | 内容 |
|---|---|
| HANDLE | ハンドル。80バイトまで。重複可、ログイン名は変えない |
| BIO | 1行自己紹介320バイト。BIOEDITの複数行自己紹介は8192バイト |
| LOCATION / OCCUPATION / INTERESTS | 地域・職業・趣味 |
| WEBSITE / CONTACT | URL・公開連絡先 |
| MACHINE / BIRTHDAY | 使用機種・誕生日（YYYY-MM-DD） |
| REALNAME / KANA / ADDRESS / PHONE | 氏名・カナ・住所・電話 |

`PROFILESET 項目 本文` で編集、`PROFILEVIS 項目 PRIVATE|MEMBERS|MONTHDAY` で公開範囲を選びます。MONTHDAYは誕生日の年を隠す指定です。HANDLEは会員公開、新しい個人情報項目は初期非公開です。本人・管理者の扱いと他会員への公開を混同しないでください。保存後の旧記録が原本やバックアップに残る場合があります。

`PROFILEFIND 項目 検索語`、`PROFILEFIND GROUP 1..100` で項目検索します。メニューの項目検索で「次の会員」が表示されたときは、Enterで同じ条件の次の会員へ進み、0で巡回を終えます。非公開情報を検索結果から漏らさないよう公開範囲を適用します。プロフィール画面のEは項目番号で編集、Sは項目と条件で検索。Webは全13項目を表示します。 編集は13項目、検索はGROUPを加えた14項目です。項目番号の0で戻れます。管理者のEでは最初に編集対象の会員番号を指定し、Enterなら本人を対象にします。

任意の互換ポリシーが有効な場合、住所・誕生日の本人変更は管理者へ依頼し、グループ検索はSIGOP以上、氏名・カナ・住所・電話の項目検索は管理者に限定されます。既存の公開設定を一括変更する機能ではありません。

## 会員設定

| 命令 | 設定 |
|---|---|
| LANG JA / EN | 日本語・英語 |
| PAGER ON / OFF、PAGER SIZE 列 行 | ページ停止・端末サイズ |
| EDITOR BETA / LINE | エディタ |
| MENUMODE BEGINNER / STANDARD / EXPERT | メニュー案内量 |
| PROTOCOL 方式 | 端末転送方式 |
| MAIL NOTIFY ON / OFF | メール新着通知 |
| /TALK ON / /TALK OFF | 個別トーク受信 |
| CHECKMODE AUTO / MANUAL | 巡回確認日時の更新方式 |

`PREFS` または設定画面Dで現在値、`PREFS SAVE` で保存、`PREFS LOAD` で再読込します。ログイン時にも復元します。通常のログアウト・終了と通信断では表示設定の保存を試みます。通常のログアウト・終了で保存に失敗すると、エラーを表示して接続を維持します。通信断後の保存は利用者へ応答できないため、障害時は管理者がログを確認してください。エディタの行番号とPROTOCOLも対象ですが、編集中の検索語・行カーソルは対象外です。

`USERLOG` は接続履歴、`USERTABLE` は接続単位の表示、`USERSTATS` は利用時間・ログイン回数です。通常は本人分、管理者はALLを指定できます。会員へのUSERLOG公開を設置者が有効にしている場合は公開範囲が広がりますが、ゲストには開放しません。

端末のメニュー命令は大小文字を区別しないよう整えますが、ログインパスワードや本文入力を一律に大文字化するものではありません。本文中の操作命令は `/CANCEL` と `/cancel` を同じように扱い、`//` で始めた入力は命令の大文字化から除外します。

## UI選択とMMM風UI

`UI` でUIの選択情報を表示し、`UI 名前` で主メニューから切り替えます。会員の希望は即時保存します。`UI RESET` は局の既定に戻り、保存済み希望を解除します。未ログイン時の選択は接続中のみです。編集・転送・Doorなどの途中では切り替えません。局の既定はRTBBS風の `rtbbs` です。

局のFIXED/MEMBERS/ALLと許可一覧が保存値より優先します。禁止・未導入UIの希望は保持したまま既定へ戻ります。ログイン前にその接続で明示選択したUIは、ログイン時の保存値で上書きしません。保存に失敗すると通知します。

局が許可した場合に `UI mmm` でMMM風インターフェースを試せます。会員ログイン後、主メニューからメール、ノート、保管庫、チャット、設定、ゲームに進みます。案内は `?`、主メニューのコマンドごとの書式は `コマンド -?` です。設定の `lang ja|en` と `size 列 行` は `save` で保存します。機能の提供条件は局の設定・利用権限に従います。

`new` はMMMで前回確認した時刻以降の閲覧可能な記事を巡回します。`scanlist` で現在の巡回先を確認し、`scanlist set #3 @synth #1` のように指定すると、会員ごとに最大64ボードを指定順に保存できます。`@syn*` や `@t?st` はアクセスラベルのパターン、`*` は閲覧可能な全ボード、`!#3` は除外です。`scanlist set -i #3 -x @syn* !#2` のように項目の前に `-i`（索引）または `-x`（新着がなければ索引）を指定できます。ワイルドカードは巡回開始時のボードと権限で評価します。`scanlist reset` または `scanlist -d` で閲覧可能な全ボードを対象に戻します。個人リストではアクセスを失ったボードを飛ばし、閲覧できる巡回先がなくなった場合は空の結果を表示します。

`open -s @synth` と `open -x @synth` は、指定したボードの最初の新着記事を開きます。新着がなければ `-s` は元の画面へ戻り、`-x` は索引を表示します。 `@synth` は[全体管理者が割り当てるアクセスラベル](board-admin.md#mmm-access-label)です。従来の `#番号` と表示名も使えます。

通常の `new`、`new -n` または `open -s/-x` で本文を読み、主メニューで `off` を使うと、今回のログイン時刻が次回の基準になります。`off -n` と通信断では更新しません。`new -n` は前回の基準時刻から新着を連続表示します。`open -n #3` は指定ボードの未読、`open -n -a #3` は同じボードの既読を含めて表示します。連続表示中にキーを押すと中断でき、`C` で再開、`Q` で巡回を終了できます。`setsequencer` で基準時刻を確認し、`setsequencer YYYY-MM-DD` または `setsequencer reset` で接続中だけ調整できます。

ノートメニューの `retitle 番号 題名` と `withdraw 番号 confirm` は、選択中のボードの記事を対象とします。権限と共有ボードの扱いはRTBBS風UIと共通です。編集中の `s` で記事を下書きに保存し、`draft resume` で再開、`draft drop confirm` で削除します。投稿後も保存済みの下書きは残ります。

設定メニューの `find 語句`、`findfield 項目 語句`、`ingroup グループ番号` は、会員のプロフィールを検索します。`privacy 項目 private|members|monthday` は公開範囲の設定です。`monthday` は誕生日の月日だけを公開します。

`pfile` は接続中だけの10KiBのパーソナルファイルです。記事読書中の `s`、メールメニューの `save 番号` で本文を追加します。`pfile -t` で表示、`pfile -e` で編集、`pfile -d confirm` で消去できます。記事やメールの編集中は `g` で本文に取り込めます。

`pfile -b` でPC上のテキストを取り込めます。端末でログインし、MMMの保管庫またはメール画面で `protocol zmodem` か `protocol ymodem` を選びます。主メニューへ戻って `pfile -b` を入力し、端末のファイル送信を開始します。既定はZMODEMです。XMODEM系を選んだ場合は、ファイルの正確なバイト数を調べて `pfile -b バイト数` を使います。

UTF-8のテキスト1件を、受信時と改行変換後の両方で10,240バイトまで受け付けます。先頭のUTF-8 BOMを取り除き、改行をCRLFに揃えます。不正な文字コードや改行以外の制御文字を含むファイルは拒否します。成功すると現在の内容を置き換え、空ファイルなら消去します。中断や失敗時は元の内容を保持します。受信したファイルは保管庫・メール添付へ登録されず、ログアウト・切断で消去されます。

`regsign -e` で署名を編集し、エディタの `w` で保存します。`regsign -t` は確認、`regsign -d confirm` は消去です。`regsign -a` で有効にすると記事の返信とメールの送信時に自動で付けます。`regsign -n` で停止できます。

## MASH風UI（開発版）

局が許可していれば、Telnetまたは内蔵SSHでログインし、主メニューで `UI mash` を入力します。操作中のUIは `UI` で確認できます。管理者は `--ui-allow rtbbs,mmm,mash` で候補に追加し、MASHを接続時の既定にするときは `--ui-default mash` を指定します。既定のRTBBS風は、設定で変更するまで維持されます。MASHの機能にはログインが必要です。

| 番号 | 操作 |
| --- | --- |
| 1 / 2 | `mail` メール / `bbs` 掲示板 |
| 3 / 4 / 5 | `setup` 通信環境 / `pprof [ID]` プロフィール / `filer` ライブラリ |
| 6 / 7 / 8 | `others` オンライン操作 / `off` 終了 / `whoami` 自分の情報 |
| 9 / 10 | `manual` 操作案内 / `map` ボード階層 |
| 12 / 13 / 14 | `readnews -n` ニュースの連続表示 / `new -n` 記事新着巡回 / `talk -n` 一行会議の未読巡回 |

`cmdlst` でコマンド一覧、`コマンド -?` で書式を確認します。`/` で主メニュー、`.` で一つ戻ります。「オンライン操作」の1は接続一覧（`who`、`w`）、2はチャット（`chat`、`c`）、3は一行会議、4はゲームです。ゲームはLiner Notes拡張で、ゲーム終了後はゲーム一覧へ戻ります。`version`（`v`）でLiner Notesの版を確認できます。

`! 接続番号 本文` は現在接続中の1人への電報です。`$` または `$ 本文` でオンラインのSYSOPを呼び出します。受信設定、連投制限、チャットの有効・無効は局の共通設定に従います。チャット中は `/w` で接続一覧を確認できます。 `bye` も `off` と同様に接続を終了します。

`readnews` は局が指定したニュースボードの索引を開きます。 `readnews -n` は既読も含めて連続表示します。管理者がニュース用の公開ボードに `BOARDLABEL 番号 mash-news` を設定すると使えます。そのボードの閲覧・投稿権限は通常の[ボード設定](board-admin.md#mmm-access-label)に従います。 `sets` は記事巡回の基準日時の表示、`sets YYYY-MM-DD` と `sets reset` は接続中だけの変更です。

返信を読んでいるときの `p` は直接の親へ移動し、`w` は表示中の記事へ返信します。 `p` はLiner Notes拡張です。スレッド、記事の可視性、会員データ、[一行会議の部屋と既読位置](conversation.md)は他のUIと共通です。パーソナルファイルは同じ接続内でもMMMとMASHで別々に保持します。

公開局の例で11番にあった局専用ダウンロード、お別れ文付き `bye`、複数宛先・強制・ファイル入力の電報、MASHの追加 `pfile` オプションは提供範囲外です。端末の文字コードは既存のUTF-8を使用します。

## KTBBS風の端末操作

局が許可しているときは、主メニューで `UI ktbbs` を選びます。接続時に `User ID` が出た場合はLiner Notesの会員IDを入力し、続く秘密入力でパスワードを入力します。入会の受付は局の設定に従い、`REGISTER ID` を使います。既存の会員情報、記事、メール、既読状態は他のUIと共有します。

| 入口 | 操作 |
|---|---|
| `R` 読書 | ボード番号・名前を入力。`?` で選択肢、`L` で続き。ボード内の `L` は記事一覧、`R` は題名から順次読書、`I` は記事IDを直接指定、`S` は投稿者または題名・本文検索。 |
| `E` 書込 | `W` 新規投稿、`R` 返信、`M` メール。題名を確認して本文を入力し、行頭の `//` だけで編集メニューへ。 `S` 送信、`L` 再読、`C` 追加、`0` 中止。 `save` はLiner Notesの下書き保存。 |
| `N` 新着 | 日付を省略すると保存済みの巡回位置を使用。 `YY/MM/DD` と `YYYY-MM-DD` を受け付けます。 `N@` で連続表示し、`C` または Ctrl+C で中断、`Y` で続行。 |
| `M` メール | Enterで順次読み出し、`L` で送信・受信一覧。 `I ID` 直接閲覧、`R ID` 返信、`K ID` 削除確認、`S 語句` 検索。添付一覧・転送・下書きには `files`、`upload`、`get`、`getall`、`resume` も使えます。 |
| `F` 保管庫 | パスまたは一覧の番号で選択。 `L` 一覧、`S` 検索、`N 日付` 新着、`X/Y/Z/M` 転送方式、`U` 登録、`D` 取得。 `cd`、`resume`、`add`、`batch` で追加の保管庫操作。 |
| `C` チャット | そのまま発言。 `W` 接続者一覧、`T 接続番号` で個別に送信、`S` SYSOP呼び出し、`//` で退出。 |
| `I` 設定 | `lang ja` または `lang en`、`size 列 行`、`pager on` または `pager off`。`save` で会員設定を保存。 |
| `!` Liner Notes拡張 | `games`、`talk`、権限を持つ利用者の `manage`、記事の `draft resume`。ゲーム終了後はゲーム一覧へ戻ります。 |

記事一覧の左端はそのページ内の選択番号で、`#` 付きの番号が記事IDです。本文の読書中は Enterで次へ、`P` で前へ、`R` で返信します。本文を表示したあとは `D` で返信元へ移動できます。本文のページ停止中は Enterまたは空白で続き、`0` でページ表示を中止します。主メニューの `?` で案内を再表示し、`G` で接続を終了します。

KTBBS風の端末モードでは会員認証が必要です。利用できる機能や公開範囲は局の設定と共通のアクセス権に従います。このUIはUTF-8を使います。DOS版の通信制御や旧ゲストIDの自動発行はありません。

## BIG-Model風の端末操作

対応版で局が許可していれば、ログイン後の主メニューで `UI big-model` を入力します。接続時に `ID >` が出た場合は、既存の会員IDでログインします。入会の可否は局の設定に従います。

| 場面 | 操作 |
|---|---|
| 主メニュー | `B` SIG・掲示板、`M` メール、`P` 保管庫、`C` チャット、`T` 電報、`U` 設定、`W` 接続一覧、`E` 終了。コマンドはEnterで確定。 `?` または `H` で案内。 |
| SIG | ページに表示された番号で選択、`L` で続き、`0` で上位、`/` で主メニュー。ボードの `B` は配下のSIG・ボード。 |
| 記事 | `R` 一覧、`R 番号` 本文、`W` 新規、`A` 表示中の記事に返信、`S 語句` 検索。本文では `N/P` で記事番号順に移動、`G` で返信元、`0` で戻る。編集は本文を `.` だけの行で閉じてから `w` で保存。 |
| 新着 | 主メニューの `N` は未読、`O` は既読を含む見出し、`X` は個人探索表を使わない全SIG。ボード内の `N` はそのボード、`X` は配下。日付を指定するとその日以降の一覧。 `Q` で中断し、主メニューの `N resume` で再開。 |
| 電報 | 主メニューで `T`、掲示板・チャットで `!`。一覧から宛先番号を入力し、UTF-8で21文字までの電文を送ります。 `/CANCEL` で中止。チャット終了は `/leave`。 |
| メール | `R [番号]` 一覧・本文、`N` 未読、`W 会員ID` 新規、`A 番号` 返信、`K 番号 confirm` 削除。添付や下書きは `files`、`upload`、`get`、`getall`、`resume`。 |
| 保管庫 | `L` 一覧、`S パターン` 検索、`I 番号` 詳細、`D 番号` 取得、`U [説明]` 登録、`R` 再開。 `protocol` で方式選択、`add` と `batch` で一括取得。 |
| 端末設定 | `1` メニュー表示量、`2` パスワード、`3` プロフィール、`4` 会員一覧、`5` 探索日仮設定。 `6 #2 #1` で探索順を保存、`6 RESET` で解除、`7` で個人設定、`8` で既定を表示。 `9 ON/OFF` は共通の個別トーク受信設定、`10 方式` は転送方式。 |
| Liner Notes拡張 | 主メニューの `+` から `talk`、`games`、`manage`、`draft`。ゲーム終了後はゲーム一覧に戻ります。 |

新規記事と返信を同じ段に並べます。最低5桁の `NUM` が記事IDで、大きな番号もそのまま表示します。日時は局のタイムゾーンです。返信の親子関係と既読は他のUIと共有し、見出し表示だけでは既読にしません。日時仮設定は接続中の探索にだけ反映します。

旧来の自動ダウンロード、アンケート、ハムレット、BigMAP専用の動作は未対応です。端末入出力は既存のUTF-8を使います。

## WANI-BBS風UI

WANI-BBS風UIの対応版で局の許可がある場合は、主画面で `UI wani-bbs` を指定します。`Login>` には既存の会員IDを入力します。 `b` で掲示板、 `p` でプログラムコーナー、 `s` で設定、 `g` でゲームへ進みます。 `b ボード名`、`b #番号`、`cd /system/mail` で直接移動できます。 `l` は一覧、`q` は上位へ戻る操作、`cd /` は主画面、`?` は現在の操作案内です。

- 通常掲示板では、新規記事と返信を同じ一覧に番号順で表示します。番号で閲覧、Enterで次、`B` で前、`F 語句` で検索、`W` で返信、`post` で新規投稿します。
- マルチノーツでは一覧の番号で表紙を読み、表紙から `.` でページの一覧を開きます。ページ番号はその画面で表示された番号を使います。 `W` でノートへページを追加し、`S` と `U` で購読を変更します。記事番号と返信関係は他のUIと共通です。
- `read` は通常掲示板、`open` はマルチノーツを巡回します。 `open -f` は購読のみ、`-s` は新着、`-i` は索引、`-x` は新着がなければ索引を表示します。 `open -s comp.*` のように対象を指定できます。 巡回中の `Q` は次のボードへ進み、全対象の巡回が終わると基準を更新します。対象指定や購読だけの巡回では、全体の基準を更新しません。`q` は更新せずに進み、`Z` は中断、`z` は基準を更新して中断します。 `seqset` で基準を表示し、`seqset YYYY-MM-DD` または `seqset reset` で変更します。
- 記事やメールを読んでいるときに `S` で一時ファイルを置き換えます。10KiBまで保持でき、`type` で参照、`edit` で編集します。エディタでは `R` で挿入、`Y` で引用、`K` で消去できます。本文入力後に単独の `.`、次いで `W` で保存します。一時ファイルの寿命は接続中です。
- `topic` は簡易伝言板の未読を表示します。 `topic -w 本文` で発言、`topic -d 番号` で自分の発言を削除します。 `topic $` は最新まで既読、`topic $,1` は逆順、`topic 100,` は指定番号からの履歴です。 `topic more` で続きを表示します。 `chat` はリアルタイム会話、`talk` はLiner Notesの一行会議です。
- `mail` で受信箱、`mail 会員ID` で送信します。 `p` の画面では `l` で一覧、`r 番号` で情報、`w 説明` で登録、`x 番号` で取得できます。 `g` から番号を選んでDoorを起動し、終了するとゲームの画面に戻ります。

<a id="net-cock-ui"></a>

## NET-COCK風UI

対応版で局が許可している場合は、主画面の `UI net-cock` で切り替えます。`ID>` にはLiner Notesの会員IDを入力します。`MODE MENU` は番号メニュー、`MODE COMMAND` はコマンド入力です。設定は会員ごとに保存されます。`?` で現在の操作案内が出ます。

| 操作 | コマンド |
|---|---|
| 掲示板を開く／新規投稿 | `BREAD`／`BWRITE`（`B`／`BW`）。`B #番号` または `B ボード名` で直接開きます。番号選択や一覧に表示された文字でグループへ進みます。 |
| 本文と題名 | ヘッダーで `R` またはEnterを押すと本文を読み、次のヘッダーへ進みます。`N/B/T/E` は次・前・先頭・末尾。`A/L` は題名一覧、`MORE` は続きです。 |
| 返信と移動 | `P` は選択中、`F` は最後に本文を表示した記事へ返信します。`U` は返信元、`I` は移動前へ戻ります。 |
| 投稿確認 | 単独の `.` で本文入力を終了。 `Y` またはEnterで確定、`N` は破棄、`T` は題名、`E` は本文の編集、`C` は確認、`Q` は下書き保存です。`DRAFT ARTICLE` または `DRAFT MAIL` で再開します。 |
| 巡回 | `BSET` で購読、`RALL` は新着を1件ずつ、`RNALL` は連続で読みます。`PMOVE T/E/L` は先頭・現在・前回ログイン、`PMOVE D YYYY-MM-DD` は指定日です。 |
| メール | `MREAD` は受信箱、`MWRITE 会員ID` は送信、`MCHECK` は送信済み一覧です。 `D` の削除は現在の項目の確認後に実行されます。 |
| プログラムボード | `PDS` で保管庫、`R 番号` で説明、`X/Y/Z` で取得方式を選択、`S` はバッチ追加、`W` は登録です。`BATCH` で一覧や転送を操作し、`O` は全件成功したときに切断します。 |
| チャット | `CHAT` で入室、`.L` は回線一覧、`.P 回線番号 本文` は個別送信、`.C 本文` はSYSOP呼び出し、`.Q` は退出です。 |
| Liner Notes拡張 | `EXCOM` で `TOPIC`、`TALK`、`FIND`、`DRAFT`、`GAMES`、`ADMIN`、`UI` の案内を確認できます。 |

<a id="vs-ui"></a>

## VS風UI

局が許可していれば、主画面の `UI vs` で切り替えられます。英字命令は大文字・小文字と全角・半角を受け付けます。`H` で現在の画面の案内、`O` で終了します。

- `B` で掲示板を選び、`L` で題名、`R 記事番号` で本文、本文の画面から `S` で関連記事を表示します。通常の一覧では返信も記事番号順に並びます。
- `N` はニュースの逐次読み、`NA` は一気読みです。`U` → `B` → `N NUMBER` または `N RELATED` で、記事番号順と返信グループ順を選べます。ボードを読み終えるとVSの巡回ポインタが進みます。途中で中断すると、次回同じボードを一部読み直す場合があります。
- `D;W;#1;題名;Y` はボード1への投稿入力に進みます。本文の次の行で `/POST` を入力して確定します。ジャンプレスの `J`／`DJ` は未対応です。
- `M` はメール、`F` はファイル保管庫、`C` はチャット、`/T` は電報です。`GAMES`、`TALK`、`TOPIC` はLiner Notes拡張です。
