# プロフィールと個人設定

## プロフィール

`PROFILE` は自分、`PROFILE ログイン名` は相手、`PROFILES [検索語]` は一覧・検索です。`+` で続き、番号で詳細を表示します。利用停止会員は通常一覧に表示しません。

| 項目 | 内容 |
|---|---|
| HANDLE | ハンドル。80バイトまで。重複可、ログイン名は変えない |
| BIO | 1行自己紹介320バイト。BIOEDITの複数行自己紹介は8192バイト |
| LOCATION / OCCUPATION / INTERESTS | 地域・職業・趣味 |
| WEBSITE / CONTACT | URL・公開連絡先 |
| MACHINE / BIRTHDAY | 使用機種・誕生日（YYYY-MM-DD） |
| REALNAME / KANA / ADDRESS / PHONE | 氏名・カナ・住所・電話 |

`PROFILESET 項目 本文` で編集、`PROFILEVIS 項目 PRIVATE|MEMBERS|MONTHDAY` で公開範囲を選びます。MONTHDAYは誕生日の年を隠す指定です。HANDLEは会員公開、新しい個人情報項目は初期非公開です。本人・管理者の扱いと他会員への公開を混同しないでください。保存後の旧記録が原本やバックアップに残る場合があります。

`PROFILEFIND 項目 検索語`、`PROFILEFIND GROUP 1..100` で項目検索します。メニューの項目検索で「次の会員」が表示されたときは、Enterで同じ条件の次の会員へ進み、0で巡回を終えます。非公開情報を検索結果から漏らさないよう公開範囲を適用します。プロフィール画面のEは項目番号で編集、Sは項目と条件で検索。Webは全13項目を表示します。 編集は13項目、検索はGROUPを加えた14項目です。項目番号の0で戻れます。管理者のEでは最初に編集対象の会員番号を指定し、Enterなら本人を対象にします。

任意の互換ポリシーが有効な場合、住所・誕生日の本人変更は管理者へ依頼し、グループ検索はSIGOP以上、氏名・カナ・住所・電話の項目検索は管理者に限定されます。既存の公開設定を一括変更する機能ではありません。

## 会員設定

| 命令 | 設定 |
|---|---|
| LANG JA / EN | 日本語・英語 |
| PAGER ON / OFF、PAGER SIZE 列 行 | ページ停止・端末サイズ |
| EDITOR BETA / LINE | エディタ |
| MENUMODE BEGINNER / STANDARD / EXPERT | メニュー案内量 |
| PROTOCOL 方式 | 端末転送方式 |
| MAIL NOTIFY ON / OFF | メール新着通知 |
| /TALK ON / /TALK OFF | 個別トーク受信 |
| CHECKMODE AUTO / MANUAL | 巡回確認日時の更新方式 |

`PREFS` または設定画面Dで現在値、`PREFS SAVE` で保存、`PREFS LOAD` で再読込します。ログイン時にも復元します。通常のログアウト・終了と通信断では表示設定の保存を試みます。通常のログアウト・終了で保存に失敗すると、エラーを表示して接続を維持します。通信断後の保存は利用者へ応答できないため、障害時は管理者がログを確認してください。エディタの行番号とPROTOCOLも対象ですが、編集中の検索語・行カーソルは対象外です。

`USERLOG` は接続履歴、`USERTABLE` は接続単位の表示、`USERSTATS` は利用時間・ログイン回数です。通常は本人分、管理者はALLを指定できます。会員へのUSERLOG公開を設置者が有効にしている場合は公開範囲が広がりますが、ゲストには開放しません。

端末のメニュー命令は大小文字を区別しないよう整えますが、ログインパスワードや本文入力を一律に大文字化するものではありません。本文中の操作命令は `/CANCEL` と `/cancel` を同じように扱い、`//` で始めた入力は命令の大文字化から除外します。

## UI選択とMMM風UI

`UI` でUIの選択情報を表示し、`UI 名前` で主メニューから切り替えます。会員の希望は即時保存します。`UI RESET` は局の既定に戻り、保存済み希望を解除します。未ログイン時の選択は接続中のみです。編集・転送・Doorなどの途中では切り替えません。局の既定はRTBBS風の `rtbbs` です。

局のFIXED/MEMBERS/ALLと許可一覧が保存値より優先します。禁止・未導入UIの希望は保持したまま既定へ戻ります。ログイン前にその接続で明示選択したUIは、ログイン時の保存値で上書きしません。保存に失敗すると通知します。

局が許可した場合に `UI mmm` でMMM風インターフェースを試せます。会員ログイン後、主メニューからメール、ノート、保管庫、チャット、設定、ゲームに進みます。案内は `?`、主メニューのコマンドごとの書式は `コマンド -?` です。設定の `lang ja|en` と `size 列 行` は `save` で保存します。機能の提供条件は局の設定・利用権限に従います。

`new` はMMMで前回確認した時刻以降の閲覧可能な記事を巡回します。`scanlist` で現在の巡回先を確認し、`scanlist set #3 @synth #1` のように指定すると、会員ごとに最大64ボードを指定順に保存できます。`@syn*` や `@t?st` はアクセスラベルのパターン、`*` は閲覧可能な全ボード、`!#3` は除外です。`scanlist set -i #3 -x @syn* !#2` のように項目の前に `-i`（索引）または `-x`（新着がなければ索引）を指定できます。ワイルドカードは巡回開始時のボードと権限で評価します。`scanlist reset` または `scanlist -d` で閲覧可能な全ボードを対象に戻します。個人リストではアクセスを失ったボードを飛ばし、閲覧できる巡回先がなくなった場合は空の結果を表示します。

`open -s @synth` と `open -x @synth` は、指定したボードの最初の新着記事を開きます。新着がなければ `-s` は元の画面へ戻り、`-x` は索引を表示します。 `@synth` は[全体管理者が割り当てるアクセスラベル](board-admin.md#mmm-access-label)です。従来の `#番号` と表示名も使えます。

通常の `new`、`new -n` または `open -s/-x` で本文を読み、主メニューで `off` を使うと、今回のログイン時刻が次回の基準になります。`off -n` と通信断では更新しません。`new -n` は前回の基準時刻から新着を連続表示します。`open -n #3` は指定ボードの未読、`open -n -a #3` は同じボードの既読を含めて表示します。連続表示中にキーを押すと中断でき、`C` で再開、`Q` で巡回を終了できます。`setsequencer` で基準時刻を確認し、`setsequencer YYYY-MM-DD` または `setsequencer reset` で接続中だけ調整できます。

ノートメニューの `retitle 番号 題名` と `withdraw 番号 confirm` は、選択中のボードの記事を対象とします。権限と共有ボードの扱いはRTBBS風UIと共通です。編集中の `s` で記事を下書きに保存し、`draft resume` で再開、`draft drop confirm` で削除します。投稿後も保存済みの下書きは残ります。

設定メニューの `find 語句`、`findfield 項目 語句`、`ingroup グループ番号` は、会員のプロフィールを検索します。`privacy 項目 private|members|monthday` は公開範囲の設定です。`monthday` は誕生日の月日だけを公開します。

`pfile` は接続中だけの10KiBのパーソナルファイルです。記事読書中の `s`、メールメニューの `save 番号` で本文を追加します。`pfile -t` で表示、`pfile -e` で編集、`pfile -d confirm` で消去できます。記事やメールの編集中は `g` で本文に取り込めます。

`pfile -b` でPC上のテキストを取り込めます。端末でログインし、MMMの保管庫またはメール画面で `protocol zmodem` か `protocol ymodem` を選びます。主メニューへ戻って `pfile -b` を入力し、端末のファイル送信を開始します。既定はZMODEMです。XMODEM系を選んだ場合は、ファイルの正確なバイト数を調べて `pfile -b バイト数` を使います。

UTF-8のテキスト1件を、受信時と改行変換後の両方で10,240バイトまで受け付けます。先頭のUTF-8 BOMを取り除き、改行をCRLFに揃えます。不正な文字コードや改行以外の制御文字を含むファイルは拒否します。成功すると現在の内容を置き換え、空ファイルなら消去します。中断や失敗時は元の内容を保持します。受信したファイルは保管庫・メール添付へ登録されず、ログアウト・切断で消去されます。

`regsign -e` で署名を編集し、エディタの `w` で保存します。`regsign -t` は確認、`regsign -d confirm` は消去です。`regsign -a` で有効にすると記事の返信とメールの送信時に自動で付けます。`regsign -n` で停止できます。
