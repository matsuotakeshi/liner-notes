# 接続・ログイン・会員登録

## 接続する

Telnetクライアントに設置者のホスト名・ポートを指定します。サーバーの動作確認は、**BBSが動いているホスト上で** `telnet localhost 2222` のように行います。別のPCでlocalhostを指定してもサーバーにはつながりません。Webは設置者が案内するHTTPS URLを開きます。

メニューが必要なら、本体を `--telnet --menu` で起動します。機械向け応答の `RTBBS-PROBE 1` や `ERR command` だけが出る場合は[起動障害](troubleshooting.md)を確認してください。

## 登録・ログイン

`REGISTER ログイン名` で登録を開始します。自由ID方式では1〜32文字の英小文字・数字・`_`・`-`を使用します。自動ID方式ではサーバーがIDを発行します。ハンドルとログイン名は別です。パスワードは画面の非表示入力を使い、8〜128バイトで設定します。コマンド行にパスワードを連結しません。

入会方法は設置者の `open`（登録後利用）、`approval`（承認待ち）、`closed`（登録停止）によります。詳細申請フォームではプロフィール、紹介元BBS、SYSOPへのメモ等を入力し、確認画面のYで確定、Eで再入力、`/CANCEL`で中止します。承認待ちの会員は承認後に利用できます。

`LOGIN ログイン名` の後、パスワードを別入力します。本人の表示設定を読み込み、接続案内、時間帯の挨拶、未読・下書き等を表示します。メッセージの有無や利用機能は設置者の設定に従います。ゲストは公開ボードを閲覧できますが、会員限定の機能はログインが必要です。

## パスワード・退会・終了

`PASSWD` で現在のパスワード、新しいパスワード、確認を入力します。変更後は同じ会員の他の接続が失効する場合があります。忘れた場合は管理者に再設定を依頼します。

`RETIRE CONFIRM` は退会処理です。会員番号とログイン名は再利用しません。記事や相手のメールまで一括で消す操作ではありません。管理者の自己退会は制限されます。

通常メニューの `O` / `Q` はY/Nで終了を確認し、空入力では戻ります。`QUIT` は確認なしで終了します。`LOGOUT` は会員ログアウトで、接続を終了する `QUIT` と区別します。通信断でも設定保存を試みますが、プロセス異常終了や権限失効では保証しません。

ゲストは `HANDLE 名前` で接続中の表示名を変更できます。会員登録名を変更する機能ではありません。[プロフィール](personal-settings.md)も参照してください。
