# ファイル保管庫と一括選択

## 保管庫を開く

F / `VAULT` で専用メニューへ入ります。`FILEBOARDS` は利用可能なファイルボード、`FILEBOARD パス` は現在位置の選択（ルートは `-`）、DIRは直下の子一覧です。DIR表示中は番号で子へ、`CD 子パス`、`CD ..` / 0で親へ戻ります。ルートの0はBBS主画面へ戻ります。

Lは一覧、Iは案内、Uは登録、D番号は取得、Bはバッチ、Sは検索、Nは日付新着です。現在位置を維持して操作します。親ボードの閲覧権限・共通パスワードも適用され、`FILEUNLOCK パス` で非表示入力します。パスワード解除は接続中だけで、変更・ログアウトで無効です。

## 一覧・検索・選択後の操作

一覧には属性、取得回数、説明を表示します。`FILE 番号` は詳細、番号だけなら操作画面です。TはASCII属性の本文表示、S/C/X/Y/G/Z/Mは転送方式、Bはバッチ追加、Eは説明編集、Kは削除、0は戻る操作です。

`FILESEARCH 語句`、`FILESEARCH パス|語句` は現在または指定ボードと子孫を検索します。`FILESIN パス` は配下一覧、`FILENEWS パス|YYYY-MM-DD` は配下の新着です。閲覧権限は各ファイルに適用します。`FILETYPE 番号 [バイト位置]` の続きは `+` です。

`*.LZH`、`file?.txt` のワイルドカードは英字大小を無視し、名前と拡張子を別々に比較します。`*.*` は拡張子なしにも一致し、`?` はDOS式の末尾空白にも一致します。通常の語句検索とは区別してください。

## 登録・取得

U / UBは方式→説明→必要なら名前・サイズを尋ねます。`UPLOAD パス|説明` / `UPLOADBATCH パス|説明` と `DOWNLOAD 番号` はPROTOCOL選択方式です。XMODEM・TEXTの単体登録は `パス|名前|バイト数|説明`。TEXTのサイズ0はCtrl-Zまで受信します。

`ZUPLOAD [説明]` の直接指定はルート登録です。別ボードなら `ZUPLOADIN パス|説明`。`ZDOWNLOAD 番号 [保存名]`、`ZUPLOADBATCH ボード|説明` はZMODEM固定です。**保管庫メニューのUは現在ボード、直接ZUPLOADはルート**という差に注意してください。

転送終了後もBBSが登録を続ける場合があります。100%は書き込み量で、公開成功は最後の登録完了表示で確認します。方式・上限・中断再開は[転送](transfers.md)にまとめています。

## 一括ダウンロード

`BATCH ADD 番号`、`REMOVE 番号`、`LIST`、`CLEAR`、`SEND` を使用します。`BATCH MATCH *.LZH` は**現在ボード内だけ**で選択を置き換えます。配下検索とは範囲が異なります。最大16ファイル・合計16GiBで、XMODEMとTEXTの一括送信はできません。

バッチ画面はDで方式を選んで送信、Lで一覧、Cで確認してクリア、Mで担当先へコピーします。同名ファイルはIDを前置して区別します。

DONEは完了確認済み、PENDINGは未完了です。SENDはPENDINGだけを再送し、成功分の取得回数を重複計上しません。失敗前に完了したファイルの履歴は残ります。もう一度取得する場合はREMOVE→ADDなどで選び直します。選択状態は接続中だけで、バッチコピーの完了状態とは別管理です。

## 登録後の管理

`FILEDESC 番号 説明`、`FILEDELETE 番号 CONFIRM` は登録者本人（閲覧・登録権限が必要）または管理権限を持つ担当者が使います。削除は物理回収を伴い、復元できません。

`FILESTATS [番号|ALL] [位置]` は完了確認済みの取得回数です。旧記録・失敗・スキップ・確認のない転送を成功と数えません。登録方式はFILEのPROTOCOLで確認でき、以前に記録されていないものはUNKNOWN、管理コピーはCOPYです。管理者・SIGOPの名称変更・登録者変更・公開状態・コピーは[保管庫管理](file-admin.md)を参照してください。
