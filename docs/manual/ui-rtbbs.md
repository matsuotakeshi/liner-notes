# RTBBS風UIの使い方

このページはLiner Notes v0.76の独自実装を説明します。実際に選択できるUIや機能は局の設定、接続状態、会員権限によります。原典の完全な互換や公式移植を意味しません。端末はUTF-8です。

切り替えは主画面で `UI`、`UI 識別子`、`UI RESET`、`UI CANCEL` を使用します。編集・転送・Doorなどを終了して主画面に戻ります。局設定がFIXEDの場合は選択できません。MEMBERSは会員、ALLはゲストも接続中に選択できます。会員の希望は保存され、許可一覧が優先されます。[共通のUI設定](personal-settings.md#ui選択とmmm風ui)も参照してください。

## 主メニュー


同じキーでも現在の画面によって意味が変わります。例えば主画面のFは保管庫、記事読書中のFは無停止連続表示です。迷ったら `HELP` で案内を表示し（主画面の `?` はメニュー再表示）、`MENU` で主画面へ戻ります。

| 入口 | 主な用途 |
|---|---|
| B / BOARDS | ボード選択。番号で入室 |
| E / BUFFER | 共通エディタ（新規投稿E・返信Rはボード画面） |
| F / VAULT | ファイル保管庫専用メニュー |
| M / MAIL | 会員間メール |
| C / CHAT、T / TALK、W / ONLINE | チャット・個別トーク・接続者 |
| P / PROFILE | プロフィール |
| GAME / GAMES | ゲーム専用メニュー。番号で起動、ゲーム終了後は一覧へ戻る |
| G / GATHER | 伝言板の閲覧と書き込み |
| SYSOPMAIL 題名 | 管理者宛てメール。ゲストも利用可能 |
| S / V | システム案内 / 版情報 |
| O / Q | 確認後に接続終了 |

管理者メニューは案内・終了の後、権限を持つ利用者にだけ表示します。SIGOPには担当範囲の操作を案内します。表示されることだけで権限を付与するわけではなく、実行時にも確認します。

## 掲示板と読書


### ボードを選ぶ

`BOARDS` で利用可能なボードを表示し、`BOARD 番号` または選択画面の番号で移動します。親子階層、表示順、振り分け専用のMENUノードがあります。`INFO` / `I` で現在ボードの説明と長文案内を確認します。共通パスワードがあるボードでは非表示入力で解除します。親の権限・パスワードも適用されます。

RTBBS端末の `L` / `LIST` は返信を含む記事番号順の一覧です。`NOTES` は親記事一覧、`TREE 記事番号` は返信の木を表示します。番号指定で本文を読みます。非表示・取り消し・権限のない記事は通常の本文表示の対象になりません。

### 読書中の操作

| 操作 | 動作 |
|---|---|
| Enter / CONTINUE | 次の記事 |
| P / PREV | 前の記事 |
| NEXT | 次の記事（RTBBS端末の通常一覧と同じ番号順） |
| L | 同じ本文の再表示 |
| D / PARENT | 親記事 |
| A / CHILD | 返信側へ |
| TREE | 返信ツリー |
| R | この本文への返信を作成 |
| G / GET | 本文を共通編集バッファへ取り込む |
| S | 投稿者プロフィールを表示して読書へ戻る |
| K | 権限があれば取り消しの確認へ |
| E | 権限に応じた題名・投稿者の変更 |
| + / -、+N / -N | 方向切替・相対移動 |
| F | 次から無停止連続表示。入力で停止 |
| 0 | 一覧へ戻る |

検索・連続読書では、その時点の範囲、投稿者、検索語を保持して移動します。プロフィールを見ても記事番号や読書条件を失いません。`S` で会員プロフィールを表示できないゲスト投稿者などもあります。

**読むだけでは記事を既読にしません。** `SEEN` で明示的に既読へ変更します。メールを読んだときの既読処理とは異なります。[未読管理](article-search.md)を参照してください。


## 投稿と編集


新規投稿はE、返信は記事読書中のRから、投稿先と題名を確認して本文へ進みます。返信先は元記事のボードです。ゲスト投稿は設置者が明示的に許可したボードに限られ、閲覧・投稿条件とパスワードも満たす必要があります。

`EDITOR BETA` / `EDITOR LINE` で種類を選び、編集中は `/EDITOR BETA` / `/EDITOR LINE` で切り替えます。本文は最大256KiB（設定で縮小可能）、1入力行は最大4,096バイトです。日本語は文字数とUTF-8バイト数が異なります。

ベタ入力の `//` とライン操作の `0` は終了確認へ進みます。Wで書き込み、Eで続行、0またはQで取り消し。拡張操作の `.` は即時確定です。`/CANCEL` は破棄して終了、`/SAVE` は記事では保存コピーを更新して編集を続け、メールでは下書き保存後に編集を終了します。案内文や共通バッファの編集では対象文書の保存です。SYSOP宛てメールには下書き保存がありません。


## そのほかの操作

LINECONF・TOPICは主画面から利用します。メールは `M`、保管庫は `F`、Doorは `GAMES` です。TREEとNOTESは明示的な関連表示です。一般利用者向けの操作は[コマンド索引](command-reference.md)、[エディタ](editor.md)、[UI横断表](ui-comparison.md)を参照してください。
