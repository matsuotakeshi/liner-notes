# 検索・新着巡回・未読管理

## 検索範囲を選ぶ

`SEARCH 検索語` は現在ボードの題名・本文検索です。複数ボードでは次を使います。

```text
FIND HERE alice *
FIND ALL * FreeBSD
FIND SUBTREE alice 設定
SCAN DESC SUBTREE * FreeBSD
```

HEREは現在ボード、SUBTREEは現在ボードと子孫、ALLは閲覧可能な全ボードです。投稿者に `*` で全員、検索語に `*` で語句指定なしにします。検索結果の `+` は続き、番号は該当ボードへ移動して本文を表示します。非公開・取り消し・権限外の記事を検索から取得することはできません。

`SCAN [ASC|DESC] 範囲 投稿者 語句` で条件に合う記事を連続表示します。Enter / CONTINUE、P、+N / -N、Fを使えます。STOP / 0 / Qは連続読書の終了で、接続終了ではありません。ページ停止中のQも連続表示を止めます。

## 未読を扱う

`UNREAD` で未読一覧、`NEW` で次の未読、`SEEN [番号]` で既読、`UNSEEN 番号` で未読へ戻します。`SEEN NEXT` は既読にして次へ進みます。`NOTES UNREAD` は未読のあるスレッドに絞り、`NEXTBOARD` は未読がある次の閲覧可能ボードへ移動します。

既読は会員ごとに保存します。記事・返信・検索・連続表示の閲覧だけでは既読にしません。ボード一覧の未読件数とログイン時案内は、その会員の閲覧可能範囲によります。

## 日付指定と前回確認日時

日付は `YYYY-MM-DD`、**サーバー設定タイムゾーンの午前0時以降**です。保存時刻と画面表示の基準は[日時設定](configuration.md)を参照してください。

| 操作 | 対象 |
|---|---|
| NEWS [ALL\|HERE] YYYY-MM-DD | 指定範囲の記事 |
| MAIL NEWS YYYY-MM-DD | 本人への受信メール。既読も含む |
| FILENEWS パス\|YYYY-MM-DD | 指定ファイルボードと子孫 |
| CHECK ARTICLES HERE\|SUBTREE\|ALL | 前回の記事確認日時以後 |
| CHECK MAIL | 前回のメール確認日時以後 |
| CHECK FILES [パス] | 前回のファイル確認日時以後 |

記事・メール・ファイルの確認日時は別々に保存します。巡回の開始時刻を上限にするため、巡回中に到着した項目は次回の対象になります。`CHECK NEXT` で続き、`CHECK CANCEL` で中止します。

メニューのAUTO方式では最後まで確認したときに日時を更新します。MANUAL方式では `CHECK DONE` で確定します。RAWの既定はMANUALです。途中中止・切断では日時を進めません。設定は `CHECKMODE AUTO` / `CHECKMODE MANUAL`。新着巡回と記事の既読は別管理です。

主画面や記事側のNで日付を空入力した場合は現在ボードの記事巡回です。保管庫では現在のファイルボードを使います。`BATCH MATCH` は現在ファイルボード内だけであり、配下新着検索の範囲とは異なります。
