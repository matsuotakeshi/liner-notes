# 投稿・編集・下書き・共通バッファ

## 投稿と確定

新規投稿はE、返信は記事読書中のRから、投稿先と題名を確認して本文へ進みます。返信先は元記事のボードです。ゲスト投稿は設置者が明示的に許可したボードに限られ、閲覧・投稿条件とパスワードも満たす必要があります。

`EDITOR BETA` / `EDITOR LINE` で種類を選び、編集中は `/EDITOR BETA` / `/EDITOR LINE` で切り替えます。本文は最大256KiB（設定で縮小可能）、1入力行は最大4,096バイトです。日本語は文字数とUTF-8バイト数が異なります。

ベタ入力の `//` とライン操作の `0` は終了確認へ進みます。Wで書き込み、Eで続行、0またはQで取り消し。拡張操作の `.` は即時確定です。`/CANCEL` は破棄して終了、`/SAVE` は記事では保存コピーを更新して編集を続け、メールでは下書き保存後に編集を終了します。案内文や共通バッファの編集では対象文書の保存です。SYSOP宛てメールには下書き保存がありません。

## 行の編集

| ベタ入力・共通命令 | 内容 |
|---|---|
| /PREVIEW | 保存前の確認 |
| /TITLE 題名 | 題名変更 |
| /UNDO | 直前の編集を戻す |
| /E | ライン編集へ |
| /N | 書き直し |
| /M | 行番号表示の切替 |
| /BUFFER | 共通バッファから取り込み |
| /TOBUFFER | 現在の本文を共通バッファへ保存 |

| ライン操作 | 内容 |
|---|---|
| nn、E[n] | 行選択・修正 |
| A | 追加入力 |
| I[n] | 指定行への挿入 |
| N | 書き直し |
| D範囲 | 削除。例 `D3-5`、`D-2` |
| L範囲 | 一覧 |
| Q範囲 | 引用符付加 |
| S 語句、S3-10 語句 | 全文・範囲検索。件数と一致箇所を表示 |
| M | 行番号表示ON/OFF |
| U | 連続テキスト受信。3秒無入力で編集へ戻る |

Uで既存本文がある場合、Yまたは空入力で消去、Nで追記します。受信終了は自動投稿ではありません。0→Wで確定します。入力中の `//` はライン操作へ戻ります。検索強調は端末の表示機能です。

## 保存下書きと共通バッファ

記事の `DRAFT` で保存状態と版番号、`RESUME` で再開、`DRAFT DELETE 版番号` で削除します。メールでは `MAIL DRAFT`、`MAIL RESUME`、`MAIL DRAFT DELETE 版番号` を使います。保存・削除は他接続での変更との衝突を確認します。下書きの案内が表示されても自動的には投稿されません。

`BUFFER` で独立した共通編集バッファを扱い、記事の `GET`、メールの `MAIL GET` で読書中の本文を取り込めます。取り込みは閲覧操作で、新規投稿とは分離されています。次に記事やメールのエディタから `/BUFFER` で利用します。保存下書きと共通バッファは別物です。

## 編集中の補助操作

ライン操作待ちのWは接続一覧、`#` は時刻・接続時間・人数・本人集計、`\` は接続者メモ、Tは一言トークです。**終了確認中のWは書き込み**なので、画面を確認してください。ベタ入力では `/W`、`/#`、`/MEMO 文章`、`/T 接続番号` を使います。

`/TALK [接続番号]` は継続会話、`//` で編集へ復帰します。本文・Undoは保持します。エディタ種別・行番号設定は会員設定に保存できますが、検索語や行カーソルを次回ログインまで保存する機能ではありません。

`/ONLINE` は接続一覧、`/STATUS` は状態表示、`/CALL` はSYSOP呼び出しです。`/HELP` で編集の案内を開いても本文とUndoは保持します。パスワード入力中には補助命令を実行しません。

WebUIの複数行入力では端末の編集命令を本文として安全に送信します。端末のキー操作をそのまま再現する場合は補助端末を使用してください。

## スラッシュ形式の行操作

`/LINES` で行一覧、`/REPLACE 3 本文` で置換（本文省略は空行）、`/DELETE 3` で削除、`/INSERT 3 本文` でその行の前へ挿入します。末尾の次の番号は追記です。行番号は改行単位で、端末幅の折返しを数えません。題名は1〜80バイト、本文上限にはCRLFも含みます。不正な番号・容量超過では元の本文を保持します。

`//LINES`、`//TITLE example`、`//SAVE` などは先頭スラッシュを1つ落とした本文として扱い、`..`で始めると先頭ドットを1つ落とします。命令の大小文字は区別しません。置換・挿入で渡した文字列は命令として実行しません。プレビュー中のQや/CANCELは表示だけを閉じ、本文入力中の/CANCELが入力内容の破棄です。

Undoは直前の変更1回だけでRedoはありません。表示・失敗・同値変更は履歴を更新せず、投稿・切断・ログアウト等で消えます。保存下書きにUndo履歴は保存しません。

## 記事下書きの保存コピー

会員ごとに記事下書き1件を保存します。/SAVE後の追記は次の/SAVEまで保存コピーへ反映されません。/CANCELや投稿成功で保存コピーを自動削除しないため、不要になったコピーは版番号を確認して明示削除します。再投稿すれば別記事になります。新しい投稿から既存コピーを上書きせず、RESUMEで再開して更新します。

空本文も保存できますが、投稿には本文が必要です。再開時にも閲覧・投稿権限と返信先を確認します。権限が変わって再開できない場合も保存コピーは残り、本人が版を確認して削除できます。他会員の下書きを管理者権限だけで閲覧する機能はありません。
