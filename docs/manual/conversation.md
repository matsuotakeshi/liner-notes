# チャット・個別トーク・Gather

## チャット

`CHAT` で共用チャットへ入ります。会員限定です。UTF-8の1発言は512バイト、連投間隔は0.5秒です。入室時はメモリ内の直近20件を表示します。全員退出・サーバー終了でメモリ履歴は消えます。`/QUIT` はチャット退出ではなく接続終了です。チャットの永続ログは設置者が有効にした場合に保存され、再入室の20件表示とは別です。

`//` / `/LEAVE` で退出、`/SAY 文章` で命令に似た文をそのまま発言します。Wは室外も含む接続者、`#` は時刻・接続時間・人数・本人集計、DはSYSOP呼び出し、`\` または二重バッククォートは接続者メモです。Tは一言トーク後に元画面へ戻り、`/TALK` は継続会話、`//` でチャットへ戻ります。

## 個別トークと接続者

主画面からも `ONLINE`、`TALK` を使えます。接続番号で相手を指定し、その接続だけに送ります。同じ会員が複数接続している場合も混同しないでください。相手が編集中・転送中など受信できない状態では拒否されます。

`/TALK OFF` / `/TALK ON` は受信設定です。会員設定として保存し、同一会員の接続にも反映します。`/MUTE ログイン名`、`/UNMUTE ログイン名`、`/MUTES` で最大32人を管理します。ミュートは私信と共通発言を非表示にしますが、入退室は表示します。`/REPLY` は直近の私信相手へ返信します。個別トークの本文を共通チャットログへ記録しません。保存して後で読む連絡には会員間メールを使います。

`MEMO 一言` で接続者一覧用のメモ、`CALL` でSYSOP呼び出しです。CALLの再呼び出し間隔は30秒で、チャット機能が無効な場合は利用できません。管理者不在時の返答を保証する機能ではありません。

## Gather伝言板

`GATHER` は古い伝言から読んで、その後に宛先を指定しない伝言を書きます。閲覧だけなら `GATHER READ` です。ログイン会員が使います。

1行70 Unicode文字・最大10行。`//` で保存、10行目で自動保存、`/CANCEL` で書かずに終了します。一覧の継続待ちで `//` またはQを押すと残りを省略して入力へ進みます。閲覧専用ではそのまま終了します。

既定は直近16件を保持し、再接続後も読めます。設置者の `--gather-count` で変更でき、0はGather無効です。個人宛ての非公開連絡ではありません。

## 管理とログ

管理者のチャット内 `/KICK ログイン名` はそのチャット接続を終了します。全接続の強制切断はCONNECTIONSとDISCONNECTを使います。ログ保存先・保持方法は[運用管理](operations.md)を参照してください。Webでは会話欄の上に補助操作の結果を表示します。
