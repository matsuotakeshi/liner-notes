# MASH風UIの使い方

このページはLiner Notes v0.76の独自実装を説明します。実際に選択できるUIや機能は局の設定、接続状態、会員権限によります。原典の完全な互換や公式移植を意味しません。端末はUTF-8です。

切り替えは主画面で `UI`、`UI 識別子`、`UI RESET`、`UI CANCEL` を使用します。編集・転送・Doorなどを終了して主画面に戻ります。局設定がFIXEDの場合は選択できません。MEMBERSは会員、ALLはゲストも接続中に選択できます。会員の希望は保存され、許可一覧が優先されます。[共通のUI設定](personal-settings.md#ui選択とmmm風ui)も参照してください。

## 操作とコマンド

局が許可していれば、Telnetまたは内蔵SSHでログインし、主メニューで `UI mash` を入力します。操作中のUIは `UI` で確認できます。管理者は `--ui-allow rtbbs,mmm,mash` で候補に追加し、MASHを接続時の既定にするときは `--ui-default mash` を指定します。既定のRTBBS風は、設定で変更するまで維持されます。MASHの機能にはログインが必要です。

| 番号 | 操作 |
| --- | --- |
| 1 / 2 | `mail` メール / `bbs` 掲示板 |
| 3 / 4 / 5 | `setup` 通信環境 / `pprof [ID]` プロフィール / `filer` ライブラリ |
| 6 / 7 / 8 | `others` オンライン操作 / `off` 終了 / `whoami` 自分の情報 |
| 9 / 10 | `manual` 操作案内 / `map` ボード階層 |
| 12 / 13 / 14 | `readnews -n` ニュースの連続表示 / `new -n` 記事新着巡回 / `talk -n` 一行会議の未読巡回 |

`cmdlst` でコマンド一覧、`コマンド -?` で書式を確認します。`/` で主メニュー、`.` で一つ戻ります。「オンライン操作」の1は接続一覧（`who`、`w`）、2はチャット（`chat`、`c`）、3は一行会議、4はゲームです。ゲームはLiner Notes拡張で、ゲーム終了後はゲーム一覧へ戻ります。`version`（`v`）でLiner Notesの版を確認できます。

`! 接続番号 本文` は現在接続中の1人への電報です。`$` または `$ 本文` でオンラインのSYSOPを呼び出します。受信設定、連投制限、チャットの有効・無効は局の共通設定に従います。チャット中は `/w` で接続一覧を確認できます。 `bye` も `off` と同様に接続を終了します。

`readnews` は局が指定したニュースボードの索引を開きます。 `readnews -n` は既読も含めて連続表示します。管理者がニュース用の公開ボードに `BOARDLABEL 番号 mash-news` を設定すると使えます。そのボードの閲覧・投稿権限は通常の[ボード設定](board-admin.md#mmm-access-label)に従います。 `sets` は記事巡回の基準日時の表示、`sets YYYY-MM-DD` と `sets reset` は接続中だけの変更です。

返信を読んでいるときの `p` は直接の親へ移動し、`w` は表示中の記事へ返信します。 `p` はLiner Notes拡張です。スレッド、記事の可視性、会員データ、[一行会議の部屋と既読位置](conversation.md)は他のUIと共通です。パーソナルファイルは同じ接続内でもMMMとMASHで別々に保持します。

公開局の例で11番にあった局専用ダウンロード、お別れ文付き `bye`、複数宛先・強制・ファイル入力の電報、MASHの追加 `pfile` オプションは提供範囲外です。端末の文字コードは既存のUTF-8を使用します。
