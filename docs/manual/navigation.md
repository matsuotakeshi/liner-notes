# メニューとコマンドの使い方

## 画面ごとの短縮キー

同じキーでも現在の画面によって意味が変わります。例えば主画面のFは保管庫、記事読書中のFは無停止連続表示です。迷ったら `HELP` で案内を表示し（主画面の `?` はメニュー再表示）、`MENU` で主画面へ戻ります。

| 入口 | 主な用途 |
|---|---|
| B / BOARDS | ボード選択。番号で入室 |
| E / BUFFER | 共通エディタ（新規投稿E・返信Rはボード画面） |
| F / VAULT | ファイル保管庫専用メニュー |
| M / MAIL | 会員間メール |
| C / CHAT、T / TALK、W / ONLINE | チャット・個別トーク・接続者 |
| P / PROFILE | プロフィール |
| GAME / GAMES | ゲーム専用メニュー。番号で起動、ゲーム終了後は一覧へ戻る |
| G / GATHER | 伝言板の閲覧と書き込み |
| SYSOPMAIL 題名 | 管理者宛てメール。ゲストも利用可能 |
| S / V | システム案内 / 版情報 |
| O / Q | 確認後に接続終了 |

管理者メニューは案内・終了の後、権限を持つ利用者にだけ表示します。SIGOPには担当範囲の操作を案内します。表示されることだけで権限を付与するわけではなく、実行時にも確認します。

## 入力とヘルプ

メニューの命令は大文字・小文字を区別しません。`LANG JA` / `LANG EN`、編集中の `/CANCEL` / `/cancel` は同じ命令です。本文・検索語・パスワードを自動的に大文字化するわけではありません。

`HELP READ`、`HELP POST`、`HELP EDITOR`、`HELP MAIL`、`HELP FILES`、`HELP CHAT`、`HELP PROFILE`、`HELP SETTINGS`、権限に応じた管理HELPを利用できます。全体の入口は案内・終了にまとめています。[コマンド索引](command-reference.md)ではWebの対応フォームも確認できます。

`RAW` は専用クライアント向けの応答へ切り替える操作です。通常の端末操作では `MENU` を使います。名前付きコマンドと対話型メニューを併用できます。

## ページ送りと案内量

`PAGER ON` / `PAGER OFF` で画面ごとの停止を切り替えます。初期値はOFF。停止中はEnterで続き、Qで表示を閉じ、OFFで残りを表示します。`PAGER SIZE 列数 行数` で手動サイズを指定し、Telnet端末がNAWSを通知する場合はそのサイズも使用します。

`MENUMODE BEGINNER` は案内を毎回、`STANDARD` は初回、`EXPERT` は必要時だけ表示します。[個人設定](personal-settings.md)で保存・再読込できます。長い一覧の `+` は次の一覧ページです。記事・メールの読書中は相対移動になるため画面の案内を確認してください。
