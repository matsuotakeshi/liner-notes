# 下書きの題名・行編集 — 第18段階

新規投稿・返信の本文入力中に、次のコマンドを使用できます。編集するのは未保存の下書きだけです。公開済みの記事は変更しません。

| 入力 | 動作 |
| --- | --- |
| `/LINES` | 題名と、1から始まる行番号付きの本文を表示 |
| `/TITLE 新しい題名` | 題名を変更 |
| `/REPLACE 3 新しい本文` | 3行目を置き換える |
| `/REPLACE 3` | 3行目を空行にする |
| `/DELETE 3` | 3行目を削除し、後続の番号を詰める |
| `/PREVIEW` | 保存される形で題名・本文を確認 |
| `.` | 保存 |
| `/CANCEL` | 下書き全体を破棄 |

行番号は入力した改行単位です。端末の幅による折返しは行番号を増やしません。空行も1行として数えます。削除後には番号が変わるため、必要に応じて/LINESで確認してください。置換後の文字列はそのまま本文に入り、ドットやスラッシュで始まっていても保存・取消などの操作としては実行しません。

題名は1〜80バイト、本文全体はCRLF改行を含めて16384バイトまでです。空の題名、不正な行番号、制御文字、容量超過はエラーにし、元の下書きを維持します。すべての行を削除した場合は空本文となり、文字を入力するまで保存できません。通常の入力行は引き続き末尾へ追記します。第19段階で [途中への行挿入と1回のUndo](DRAFT_UNDO.md) に対応しました。

## コマンドを本文に書く場合

本文としてコマンド行を書くには、先頭のスラッシュを1つ増やします。`//LINES` は `/LINES`、`//TITLE example` は `/TITLE example`、`//REPLACE 1 text` は `/REPLACE 1 text`、`//DELETE 1` は `/DELETE 1` の本文になります。`//PREVIEW` と先頭ドットのエスケープも従来どおり利用できます。認識するコマンドは大文字です。未知のスラッシュ行は従来どおり本文です。

## 表示と保存

行番号一覧は日英表示とPAGERに対応します。画面待ち中はEnterで続き、Qまたは/CANCELで表示だけを閉じます。下書きは残り、本文入力へ戻ります。下書きそのものを破棄するには本文入力中に/CANCELを入力してください。画面待ち中のOFFは残りを一括表示し、その接続のページ送りをOFFにします。

修正と表示は共通Sessionのメモリ上で行い、保存要求を送りません。既読状態、現在の記事、返信先、一覧の続き位置を変更しません。保存時の権限確認は従来どおり保存ワーカーで行います。入力中の未保存変更は切断で失われます。第20段階の [/SAVEとRESUME](SAVED_DRAFT.md) で明示保存したコピーは再開できます。今回の変更に保存形式の更新はありません。

rawでは/LINESに対して `DRAFT LINES 件数`、`TITLE 題名`、各行の `LINE 行番号 本文`、`END DRAFT` を返します。変更成功は `DRAFT TITLE CHANGED`、`DRAFT LINE REPLACED`、`DRAFT LINE DELETED` です。raw応答は画面分割しません。
