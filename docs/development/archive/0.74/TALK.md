# 個別トーク（stage44）

ログイン済みの相手を接続番号で選び、その接続だけに発言を送れます。送信者にも送信先を表示します。同じ会員の別接続や第三者には配信せず、共通履歴にも記録しません。

## チャット室内からの使い方

ログインして `CHAT` で入室します。`W` で室内の接続番号を確認できます。室外からの利用は末尾のstage44の説明を参照してください。

| 入力 | 動作 |
| --- | --- |
| `T 123` / `/TALK 123` | 接続番号123との個別トークに切り替える |
| `T` / `/TALK` | 相手の接続番号を入力する画面へ |
| 通常の文章 + Enter | 選んだ相手だけに送信する |
| `/REPLY` | 最後に私信を受け取った相手を送信先に選ぶ |
| `//` / `/END` | 個別トークを終了し、共通チャットへの発言に戻す |
| `/LEAVE` | チャット室から退出してBBSへ戻る |
| `/QUIT` | 退出し、接続も終了する |
| `/SAY 本文` | 予約コマンドと同じ文字列を送る。個別モードなら個別送信 |
| `?` / `/HELP` | 操作のヘルプ |

BBSからは `HELP TALK` または `HELP CHAT` で説明を表示できます。日英表示に対応し、外部メニューにも案内を追加しました。BBS画面の `T` は従来どおり記事ツリーです。

個別モードではプロンプトに相手の番号を表示します。共通チャットの会話も受信しますが、自分の送信先は選んだ相手のままです。他の人から私信が届いても、自動で送信先を変えません。返信したい場合だけ `/REPLY` を使ってください。

相手の退出・切断・会員停止後は、送信を停止した状態になります。新しい接続や同じ会員の再ログインに送り直すことも、共通チャットへ自動で切り替えることもありません。相手を選び直すか、明示的に `//` で共通チャットへ戻してください。無効な相手番号を指定した場合も、後続の文章を全員に流しません。室外トークの番号入力中は空行で中止できます。

## 範囲と構成

stage44からBBS閲覧中のログイン済み接続にも送信できます。パスワード入力中・本文編集中・転送中などの相手へは送信しません。受信拒否・ミュートは下記を参照してください。私信は保存しないため、入室時の履歴には出ません。転送済み表示は受信側の出力キューが受け付けたことを示し、本人の既読確認ではありません。

1行512バイトのUTF-8、制御文字拒否、0.5秒の発言間隔は共通チャットと共用です。個別トークは通信の暗号化を追加するものではなく、通信経路は既存のTelnetまたはSSH入口に従います。

`chat.c` は接続IDを使った対象確認・個別配信だけを担当します。私信は公開配信・履歴リングを経由しません。会員認証は既存の入口で操作ごとに確認し、`session.c` が相手選択・返信先・切断時の送信停止状態と表示を管理します。stage40では保存形式を変更していません。stage42では会員ファイルへ受信設定用の記録を追加します（下記）。

raw表示の私信は以下です（名前と本文の間はタブ）。

```text
CHAT TALK OPEN 接続番号
CHAT PRIVATE FROM 接続番号 会員ID ログイン名	ハンドル	本文
CHAT PRIVATE TO 接続番号 会員ID ログイン名	ハンドル	本文
CHAT TALK GONE
CHAT TALK CLOSED
```

## 受信設定・ミュート（stage42の動作）

チャット室内で次の操作が使えます。初期状態は個別受信ON・ミュートなしです。

| 入力 | 動作 |
| --- | --- |
| `/TALK OFF` | 全員からの私信を拒否する |
| `/TALK ON` | 個別受信を再開する。ミュートはそのまま |
| `/MUTE ログイン名` | その会員の私信を拒否し、共通発言も非表示にする |
| `/UNMUTE ログイン名` | その会員のミュートを解除する。退出済みの相手も解除可能 |
| `/MUTES` | 個別受信のON/OFFとミュート一覧を確認する |

`W` の一覧で括弧内に表示するログイン名を指定します。接続番号やハンドルではありません。登録済みの別会員を指定してください。チャット室にいない相手も指定できます。最大32会員で、同じ名前の追加は重複登録しません。

設定は会員ごとに自動保存します。退出・切断・サーバー再起動後も保持し、チャット入室時に復元します。同じ会員の別接続にも反映します。保存時の対象は会員IDで管理し、相手の再接続や別接続でも適用します。stage41の入室中だけ有効な設定から変更しました。

ミュートしても入退室通知と参加者一覧は表示します。共通発言の非表示は自分の画面だけに適用し、他の人への配信や共通履歴から削除しません。すでに届いた発言も消しません。再入室時の共通履歴でも、ミュート対象の発言は非表示にします。

拒否された私信は受信者へ本文・通知とも届けず、送信側へ「相手の受信設定により送信できない」と表示します。共通会話へ自動で切り替えません。相手が設定を解除すれば、選択中の個別送信先へ再度送れます。受信拒否は自分からの送信は止めません。

チャット本体に受信設定とミュート一覧を置き、通信や会員DBへの依存は追加していません。設定操作も既存の会員認証入口を通します。日英ヘルプの `HELP TALK` / `HELP CHAT` に案内を追加しました。

stage41の試作配置先は `/home/takeshi/liner-notes-stage41-20261026` です。

stage41はFreeBSD 15.1で関連10本のPython試験とチャット本体・アダプターのC試験、Windowsで関連9本のPython試験とチャット本体のC試験が成功しました。ミュート後の同一会員別接続、私信の非配信、共通発言の選別、解除・再入室、日英ヘルプを実接続で検証しています。検証した109ファイルのSHA-256は配布元と一致しました。記録は `evidence/freebsd-stage41.txt` と `evidence/windows-stage41.txt` です。

## stage42: 保存・復元と複数接続

`/TALK ON|OFF`、`/MUTE`、`/UNMUTE` は変更時に自動保存し、`/MUTES` で保存済み状態を確認できます。追加の保存コマンドは不要です。未設定の会員は受信ON・ミュートなしです。同じ設定を繰り返しても保存記録を増やしません。

保存担当が変更を順番に処理するため、別接続から相手を追加・解除しても、古い一覧による上書きは発生しません。同じ項目への変更は処理した順に反映します。チャット本体へは版番号付きの設定を渡し、古い結果が届いても新しい状態を戻しません。要求元が切断した場合でも、保存が完了した変更は他の接続へ適用します。個別トークの送信先選択や私信本文は保存しません。

設定の記録は既存の会員ファイル（例: `members.dat`）に追記します。既存の同期保存・ロック・検査値を利用し、記録の書き込みと同期が成功した後だけ保存済み状態を返します。保存エラーでは成功を表示せず、以降の会員データ操作も止めます。途中で切れた記録・不正な対象ID・不正な設定値は起動時に拒否し、勝手に初期化しません。

**更新時は停止中の会員ファイルをバックアップしてください。** stage41以前の会員ファイルはそのまま読めますが、stage42で新しい設定記録を保存したファイルは旧runtimeでは読めません。旧版へ戻す場合は更新前のバックアップが必要で、その後の会員データ変更は含まれません。稼働データの更新やサービス切り替えは今回行っていません。

チャット本体は会員ファイルに直接アクセスしません。保存・対象会員の解決を会員管理側で行い、独立した `ChatPreferences` をチャットへ渡します。将来、会員管理を分離する際もこの受け渡しを維持できます。

試作配置先: `/home/takeshi/liner-notes-stage42-20261026`。

stage42はFreeBSD 15.1で全49本のPython試験とC試験、Windowsで関連13本のPython試験とチャット本体のC試験が成功しました。再起動後の保存・解除、複数接続への反映、重複書き込みの抑制、ミュート済み履歴の非表示、不正記録・途中書き込みの検出を確認しています。検証した111ファイルのSHA-256は配布元と一致しました。記録は `evidence/freebsd-stage42.txt` と `evidence/windows-stage42.txt` です。

## stage44: チャット室外のトーク

BBS画面で `ONLINE` を入力し、ログイン済み接続の番号を確認します。`TALK 番号` でその相手との個別トークに入り、通常の文章を送信できます。`TALK` 単独なら番号を入力する画面になります。番号入力中の空行は中止です。`/REPLY` は直近の私信送信者とのトークを開始します。`//` / `/END` / `/LEAVE` で元のBBS画面へ戻り、`/QUIT` は接続を終了します。

室外トーク中の `W` / `/WHO` はログイン済み接続の一覧です。共通チャットへの参加は不要で、共通発言や入室履歴も配信しません。受信側の画面や送信先は自動で切り替えません。共通チャットから、室外の会員への個別送信も可能です。

本文編集中、パスワード入力中、バイナリ転送中、ページ送り待ち、処理待ち、宛先・題名入力や確認待ちなどの相手には本文を配信せず、送信側へ利用できない旨を返します。私信は蓄積しません。再送する場合は相手を選び直してください。BBSの通常プロンプトで文字入力中の場合は、受信表示のあとに入力途中の文字列を再表示します。

会員ごとの受信拒否・ミュートは室内外で共通です。ログアウト・切断・会員停止時は接続番号を無効にし、別の会員や新しい接続へ自動転送しません。室外トークから戻っても公開チャットに送信先を切り替えません。

RTBBSの主メニューTに相当する入口は `TALK` です。既存のBBS画面のT（記事ツリー）とM（メニュー）は維持します。旧RTBBSのような編集中の割り込み表示や単発送信を完全再現するものではありません。
