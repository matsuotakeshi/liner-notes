# 操作別ヘルプ — 第27段階

通常画面で `H`（小文字hも可）または `HELP` を入力すると項目一覧を表示します。`?` と `M` は従来どおりメニュー表示です。ゲストもヘルプを参照できます。

| コマンド | 内容 |
| --- | --- |
| HELP READ | ボード・親記事・返信ツリー・検索・一覧の続き |
| HELP UNREAD | 既読操作、未読記事・スレッド、ボード巡回 |
| HELP POST | 投稿・返信、本文編集、Undo、プレビュー |
| HELP DRAFT | 手動保存、再開、版競合、明示削除 |
| HELP SETTINGS | 言語、ページ送り、会員の表示設定 |
| HELP ACCOUNT | 登録、ログイン、パスワード変更 |
| HELP ADMIN | 記事の非表示・復元、会員停止、管理履歴 |

項目名は小文字も使えます（例: `HELP read`）。不明な項目には項目一覧への案内を表示します。管理ヘルプを参照しても権限は付与されず、各操作の既存の権限確認が有効です。

## ページ送りと状態維持

現在の言語で表示し、PAGER ON/OFFに従います。ページ送り中はEnterで続き、Qまたは/CANCELでヘルプを閉じ、OFFまたはPAGER OFFで残りを一括表示します。Qはページ送り中の表示終了であり、通常画面の接続終了とは異なります。

ヘルプ表示は現在ボード、選択記事、一覧の続き位置・絞り込みを変更しません。全表示または中止の後は、元の一覧の `+` や記事操作を続けられます。保存データも変更しません。

## 本文入力中

本文入力中は `/HELP` で投稿・編集の説明を表示します。本文、題名、Undo、保存下書きを維持し、終了後は本文入力へ戻ります。`//HELP` は文字どおり `/HELP` の本文行になります。通常の `HELP` や `H` は本文です。

題名・検索語・ユーザー名・パスワードなどの入力欄ではヘルプを実行しません。メニュー入力を/CANCELで中止してから通常画面でHELPを使ってください。

## raw通信と構成

rawでも `HELP` と `HELP 項目`、編集中の `/HELP` を利用できます。現在の言語でページ分割せず出力し、末尾に `END HELP` 行を付けます。従来のraw HELPコマンド一覧は項目別説明に変更したため、応答を解析するクライアントはこの終端を使ってください。Hの短縮はメニュー専用です。

説明文は既存の日英メッセージカタログに置き、セッション側で表示します。保存形式に変更はなく、Telnetと通常接続で共通です。
