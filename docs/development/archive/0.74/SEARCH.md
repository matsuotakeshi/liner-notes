# 記事検索 — 第13段階

対話メニューで `X` を入力し、検索語を入力してください。現在のボードの題名・本文から一致する記事を番号順に表示します。返信記事も対象です。検索結果で記事番号を入力すると記事を開き、`T` で返信ツリーへ移れます。日英表示とTelnetに対応します。

| 入力 | 動作 |
| --- | --- |
| `X` | 対話メニューで検索語の入力へ |
| `SEARCH 検索語` | 現在のボードを先頭から検索 |
| `+` | 検索結果画面で同じ検索語の次ページへ |
| `SEARCHFROM 開始番号 検索語` | 指定した記事番号を含めて後方を検索 |
| 記事番号 | 対話メニューでその記事を開く |

検索語は1〜80バイト、制御文字は不可です。日本語も検索できます。空白を含む文字列は、そのまま一続きの検索語になります。引用符やワイルドカードの解釈はありません。英字の大文字・小文字、全角・半角、Unicodeの異なる表現は区別します。数字だけの検索語も通常どおり検索できます。検索語の入力中は `/CANCEL` で中止できます。

検索しても現在の記事や既読状態は変わりません。記事を開いた後の `+` は検索ページ送りにはならないため、検索をやり直すには `SEARCH 検索語` を入力してください。検索語とページ位置は接続ごとに独立し、言語切替では維持します。別の一覧を開くと、その一覧のページ送りに切り替わります。

## 権限とページ送り

管理者も含め、非表示記事を検索結果に出しません。題名と本文のどちらが一致した場合も同じ扱いです。ボードの閲覧権限を保存ワーカーで確認し、現在のボードだけを検索します。ゲストも閲覧できるボードなら検索できます。検索結果には記事番号・親番号・題名を表示し、本文の抜粋は表示しません。

1ページ最大8件を表示します。1回に調べる記事番号は最大256件です。他ボードの記事や非表示記事もこの走査上限に含むため、一致する記事が0件でも次ページがある場合があります。そのときは `+` で続けてください。開始番号は1〜10000です。最新の記事番号を超える開始番号では空の結果を返します。

ページ間で投稿・非表示・復元があれば、その時点の状態を反映します。結果全体のスナップショットは保持しません。新規投稿は後続ページに現れる場合があり、既に通過した番号の記事を復元した場合は先頭から検索し直してください。ページ送りに使用する番号は全ボード共通の記事番号です。

## raw応答と拡張

```text
SEARCH 日本語
1 0 日本語の話題
4 1 日本語についての返信
END NEXT 257
```

ヘッダーは検索語、各行は記事番号・親記事番号・題名です。末尾の番号を次の `SEARCHFROM 257 日本語` に使います。0なら終端です。件数の総計は計算しません。

検索は保存ワーカーで既存のメモリ上の記事を走査します。検索用ファイルや索引は追加せず、保存形式も変更しません。入力はSession、表示はUIに分離しており、将来のCOM・Webでも同じ検索要求と権限判定を利用できます。
