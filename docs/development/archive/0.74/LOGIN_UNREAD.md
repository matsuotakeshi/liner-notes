# ログイン時の未読状況案内 — 第26段階

メニューで認証に成功すると、未読記事の総数と未読記事があるボード数を1回表示します。登録成功によってログインした場合も対象です。

```text
未読記事: 5 件 / 未読のあるボード: 4。Bで一覧、Jで次の未読ボードへ。
```

保存済みの表示言語を復元してから、日本語または英語で案内します。表示順はログイン成功、未読状況、保存下書きの案内（存在する場合）、通常プロンプトです。未読がなければ記事0件・ボード0と表示します。

## 集計対象

認証した本人が閲覧できるボードだけを対象にし、祖先ボードから継承する閲覧制限も反映します。閲覧専用ボードも含みます。親記事・返信を区別せず、本人が未読で、記事自体が非表示でないものを1件ずつ数えます。子ボードは別のボードとして数えます。

親記事が非表示でも、非表示でない返信は従来のUNREAD・ボード未読件数と同じく対象です。親記事の非表示を理由にスレッドを除外するKの絞り込み件数とは異なります。案内は件数だけで、題名・本文・非公開ボード名を表示しません。

集計は認証処理時点の情報です。その後の投稿・既読変更・非表示操作は自動反映せず、Bで現在のボード別件数を確認できます。Jは現在のボード以外の未読ボードへ移動します。未読が現在のボードにしかない場合は移動しないので、FやKを利用してください。

案内自体はボード移動・記事表示・既読処理を行わず、保存データを変更しません。認証失敗・利用停止中・未ログインでは表示しません。通常コマンドごとに繰り返すこともありません。

## 通信と保存

通常メニューとTelnetメニューに対応します。rawの認証応答は従来の `LOGGED IN 名前` の1行を維持します。rawではBOARDSで未読件数を確認できます。後からMENUへ切り替えたときにはログイン時案内を再表示しません。保存形式は変更していません。

集計は共通ワーカーで行い、会員の閲覧権限・既読記録・記事の非表示状態に基づく数値をセッションへ返します。今後のCOM・Web入出力でも同じ情報を利用できます。
