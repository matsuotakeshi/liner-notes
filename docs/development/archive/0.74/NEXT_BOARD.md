# 未読のある次のボードへ — 第23段階

ログイン後、メニューで `J`（小文字jも可）または `NEXTBOARD` を入力すると、未読記事のある次のボードへ移動します。rawモードではNEXTBOARDを使います。

- 現在のボードを除き、BOARDSと同じ階層表示順で探します。番号順とは限りません。
- 末尾まで探したら先頭へ戻り、最大1周で終了します。
- 閲覧可能で、非表示でない未読記事が1件以上あるボードを選びます。投稿権限は不要です。
- 親記事・返信はともに対象です。子ボードの記事はその子ボードの未読として扱います。
- 他のボードに未読がなければ、案内を表示し、現在ボード・選択記事・一覧の続き位置を維持します。現在のボードにだけ未読がある場合も移動しません。

移動すると従来のBOARD選択と同じく記事選択を解除し、メニューでは移動先の親記事一覧を表示します。ここからFで次の未読記事を読むか、番号で記事を選べます。巡回自体は既読状態を変更しません。PAGER ON/OFFは移動後の一覧にも適用されます。ゲストはログインを求められます。

日本語・英語、通常メニュー・Telnetに対応します。本文入力中のJやNEXTBOARDは本文として扱われます。入力を終えるか/CANCELしてから巡回してください。保存下書きは変更しません。

## raw応答と構成

成功時は既存の `BOARD 番号 題名` 応答でボードを切り替えます。rawでは一覧を自動送信しません。移動先なしは `NEXTBOARD NONE`、未ログインは `ERR login required` です。引数は受け付けません。

未読一覧と共通の集計をワーカーで行い、会員の既読状態・閲覧権限・非表示状態を使って移動先を決めます。保存形式に変更はありません。将来COM・Webから利用する場合も同じ操作を使えます。
