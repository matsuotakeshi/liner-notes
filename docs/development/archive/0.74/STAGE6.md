# 第6段階: 日本語の対話メニュー

この文書は第6段階の記録です。現在のTelnet接続とパスワード非表示入力は [第8段階](TRANSPORTS.md) を参照してください。

ボード選択 → ノート一覧 → 記事閲覧 → 返信・未読巡回を、番号と短いキーで操作できます。画面消去やカーソル制御を使わず、端末のスクロール履歴を残す行単位のUTF-8表示です。

## FreeBSDで起動

```sh
make
make test
./runtime --menu 23230 notes.dat members.dat boards.example.conf
```

FreeBSD側の別端末で `nc 127.0.0.1 23230` と接続します。接続元はUTF-8表示を使用してください。待受はlocalhostのみです。遠隔から試す場合はSSHでホストにログインしてncを使えます。

`--menu` を省略すると従来の試験コマンド表示です。その接続でも `MENU` で対話メニューに入れます。`RAW` で戻れます。

現在はraw TCPです。Telnet交渉・端末側のパスワードエコー制御・TLSは未実装です。サーバーはパスワードを返信しませんが、ncを動かす端末では入力がローカル表示されます。

## 操作

| 入力 | 動作 |
| --- | --- |
| G / L | 新規登録 / ログイン。会員名とパスワードを順番に入力 |
| B | ボード一覧。ボード番号を入力すると選択してノート一覧へ |
| N | ベースノート一覧。記事番号を入力して読む |
| W / R | 新規ノート / 現在記事への返信。題名、本文の順に入力 |
| P / C / > / < | 親 / 最初の子 / 次の兄弟 / 前の兄弟 |
| T | 現在記事が属する返信ツリー |
| U / F | 未読一覧 / 次の未読を読む |
| S / A | 現在記事を既読にする / 既読保存後に次の未読へ |
| + | 現在の一覧の次ページ |
| I / O | 会員情報 / ログアウト |
| ? / Q | メニュー / 終了 |

短い英字キーは大文字・小文字の両方を受け付けます。従来の長いコマンドも使用できます。ボード一覧では番号をボードとして、それ以外では記事として扱います。プロンプトには会員名・現在ボード・現在記事番号が出ます。

本文は `.` だけの行で保存し、`/CANCEL` で取り消します。題名・会員名・パスワード入力も `/CANCEL` で取り消せます。本文中の MENU や RAW は本文として保存されます。ドットで始まる本文行はドットを1つ追加して入力してください。

題名は80バイト、本文は改行込み1024バイトです。記事を開くだけでは既読になりません。Aは既読記録の保存成功を待ってから現在ボード内の次の未読へ進み、保存エラーでは移動しません。

## 実装と検証

- `src/ui.c` は表示専用。権限判定や保存は既存のワーカーを使用します。
- 接続別に表示位置・ページカーソル・入力段階を保持します。入力バッファ4096バイト、出力キュー16384バイトで上限を設けています。
- 本文は応答中のバイト長に従って表示するため、本文に END があっても途中で切れません。
- Windows GCCとFreeBSD 15.1-RELEASE amd64の標準ccで警告をエラー扱いにしてビルド成功。
- 既存5系列と新しい `test_ui.py` が実ソケットで成功。登録・ログイン、日本語投稿・返信、取消、記事移動、未読巡回、ボード権限、ページ送り、接続別状態、RAW/MENU切替、終了を確認。
- FreeBSDではRLIMIT_FSIZEによる実際の既読ジャーナル短書込みでも、Aが移動せず未読を保持することを確認。
