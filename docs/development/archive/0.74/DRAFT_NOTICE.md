# ログイン時の保存下書き案内 — 第21段階

メニュー表示で認証に成功したとき、本人の保存下書きがあれば、保存版番号と `RESUME`・`DRAFT` の操作案内を1回表示します。保存済みの言語設定がある場合は、その言語を復元してから案内します。日本語・英語、通常接続・Telnetに対応します。

例:

```text
保存下書きがあります（版 1）。RESUMEで再開、DRAFTで確認・削除方法を表示できます。
```

案内だけでは編集を開始せず、現在ボード・既読状態・保存データを変更しません。題名や本文も案内に表示しません。再開するには通常画面で `RESUME`、不要な場合は `DRAFT` で版番号を確認して `DRAFT DELETE 版番号` を入力してください。

下書きなし・削除済み・認証失敗・利用停止で認証できない場合は案内しません。保存後にボード権限を失っても、本人への存在案内は表示します。再開時には従来どおり閲覧・投稿権限を確認し、再開できなくても本人が明示削除できます。ログインと次の操作の間に別接続が保存・削除することがあるため、案内の版番号は認証時点の情報です。

rawモードでは従来のログイン応答を維持します。保存状態は `DRAFT` で確認できます。後からMENUへ切り替えた場合や通常のコマンド操作では、ログイン時の案内を繰り返しません。保存形式に変更はありません。手動保存・投稿後の保存コピー維持などは[下書きの一時保存・再開](SAVED_DRAFT.md)を参照してください。
