# 記事管理・横断検索・プロフィール — 第28段階

RTBBSの機能を参考に、C版の返信ツリー・権限・多言語・入出力分離に合わせて7機能を追加しました。旧RTBBSのデータ互換を実装したものではありません。

| 機能 | 操作 |
| --- | --- |
| 投稿者本人による記事削除（取り消し） | `WITHDRAW 記事番号` → `WITHDRAW 記事番号 CONFIRM` |
| 投稿済み題名変更 | `RETITLE 記事番号 新しい題名` |
| ボード横断検索 | `FIND ALL * 検索語` |
| 投稿者指定の記事抽出 | `FIND ALL ログイン名 *`、検索語との組合せも可 |
| 記事の連続読み出し | `SCAN ALL * 検索語` → Enter/CONTINUEで次の記事 |
| ボードの説明・案内 | `INFO` または `INFO ボード番号` |
| プロフィール登録・閲覧・検索 | `HANDLE`、`BIO`、`PROFILE`、`PROFILES` |

画面内の説明は `HELP CONTENT` と `HELP PROFILE` です。日英表示、Telnet、通常接続に対応します。

## 記事取り消しと題名変更

記事番号は全ボード共通ですが、取り消しと題名変更は現在のボードの記事に限定します。先にBOARDでボードを選択してください。

WITHDRAWは登録会員の投稿者本人だけが実行できます。最初のコマンドは確認案内のみで、CONFIRM付きのコマンドで確定します。管理者が他人の記事を取り消す操作は追加せず、既存のHIDEを利用します。ゲスト投稿や所有者を特定できない旧記事には本人取り消しを認めません。保存形式上、投稿者文字列guestは匿名投稿と区別できないため、guestというログイン名でも本人取り消し・本人権限での題名変更は許可しません。

確定後は通常閲覧・検索・連続読み出し・未読集計から題名と本文を除外し、記事番号と返信関係を残します。返信ツリーや通常一覧には「投稿者が取り消しました」と表示し、既存の返信は読めます。新しい返信の投稿先にはできません。保存済み返信下書きも再開・投稿時に確認します。管理者のINSPECTも取り消し本文を表示せず、RESTOREでは復元できません。

これは表示上の取り消しであり、元の記事ファイルから本文を物理消去する機能ではありません。削除前に利用者が取得済みの表示・コピーは回収しません。

RETITLEは本人または全体管理者に許可します。対象ボードの閲覧・投稿権限が必要で、非表示・取り消し記事は変更できません。題名はUTF-8で80バイトまで、本文・投稿者・投稿日・返信リンク・既読状態は変更しません。検索には変更後の題名を使います。同時変更はワーカー処理順の最後の値を採用し、履歴は追記記録に残ります。送信者情報の書き換えや投稿済み本文編集は対象外です。

## 検索と投稿者指定

```text
FIND HERE * FreeBSD
FIND ALL * FreeBSD
FIND ALL alice *
FIND HERE alice 設定
```

HEREは現在ボード、ALLは閲覧できる全ボードです。祖先の閲覧制限も反映し、非表示・取り消し記事は除外します。投稿権限は不要です。

投稿者は変更可能なハンドルではなく、固定のログイン名を完全一致で指定します。`*` は投稿者または検索語の条件なしを意味し、文字列内のワイルドカードではありません。検索語は題名・本文へのUTF-8バイト列の部分一致で、大文字・小文字を区別します。最大80バイトです。

結果には記事番号・ボード番号・親番号・題名を表示します。メニューでは結果番号を選ぶと権限を再確認して対象ボードへ移り、その記事を読みます。単なる検索ではボードも既読状態も変更しません。`+` は検索条件を維持して次の取得ページへ進みます。

1要求の走査は256記事、表示は最大8件です。途中で該当なしのページでも続きがある場合があります。既存のSEARCHは現在ボード限定のまま利用できます。

## 連続読み出し

SCANはFINDと同じ条件指定で、記事番号の昇順に本文を読みます。

```text
SCAN HERE * *
SCAN ALL alice *
SCAN ALL * FreeBSD
```

最初の該当記事を表示し、EnterまたはCONTINUEで次へ進みます。STOP、Q、/CANCELで中止します。他の通常コマンドを入力すると連続モードを終えて、そのコマンドを実行します。終端で終了案内を表示します。読み出しでは既読にしません。

PAGER ONの場合は記事内の画面送りが先に行われ、記事末尾の通常プロンプトでEnterを押すと次の記事へ進みます。画面送り中はEnterで次の画面、Qまたは/CANCELで連続モードごと中止、OFFで残りを一括表示します。画面送り中のSTOPはページ送り操作ではないため、Qを使ってください。

各記事取得時に現在の権限・非表示・取り消し状態を再確認します。ALLでは記事のあるボードへ移動するため、中止後は最後に読んだボードと記事が選択されています。自動タイマーで全記事を送り続ける機能ではありません。

## ボード説明

ボード設定の任意の6項目目に、1行の説明文を指定します。従来の5項目形式もそのまま読めます。

```text
1|0|all|member|General|ようこそ。最初にHELPで操作を確認してください。
2|1|member|member|FreeBSD|FreeBSDの設定や運用について話すボードです。
```

説明はUTF-8で320バイトまで。制御文字と区切りの `|` は使用できません。設定は起動時に読み込むため、変更反映には再起動が必要です。INFOは閲覧権限を確認し、説明を表示するだけでボードを移動しません。ボード設定のオンライン編集は今回の対象ではありません。

## 公開プロフィール

```text
HANDLE たけし
BIO FreeBSDとレトロPCが好きです。
PROFILE
PROFILE alice
PROFILES FreeBSD
```

HANDLEは80バイト、BIOは1行320バイトまで。引数なしのHANDLE/BIOはその項目を消去します。編集対象は本人のみです。更新は即時保存し、再ログイン・再起動後も保持します。

PROFILEは自分、PROFILE ログイン名は指定会員の情報を表示します。PROFILESはログイン名・ハンドル・自己紹介を部分一致検索し、省略または `*` で会員一覧になります。最大8件ずつ取得し、`+`で続き、番号選択でプロフィールを表示します。利用停止中の会員は検索・閲覧から除外します。

プロフィールの閲覧・検索はログイン会員に公開します。個別の公開範囲設定はありません。ハンドルは重複でき、ログイン名や記事の投稿者名を変更しません。住所・電話・実名などの専用項目は追加していません。消去や変更前の値も管理用の追記ファイルには残ります。

## 永続記録・バックアップ・互換性

記事ファイルの隣に `<記事ファイル>.extras` を作成します。記事取り消し、題名変更、ハンドル、自己紹介を記録します。記事・会員・moderation・extras・ボード設定をセットでバックアップしてください。

このファイルは今回の機能の正本です。**extrasを失う、または第27段階以前の実行ファイルを使うと、取り消し・題名変更が反映されず元の記事が見えるため、運用データで旧版へ戻さないでください。** 新版は既存の旧形式の記事・会員データをそのまま読み、既存ファイルを書き換えません。

形式はRTEXTRA1（8バイト）と512バイト固定長レコードです。種別D/T/H/B、予約3、連番4、対象ID4、操作者ID4、文字列バイト長4、データとゼロ埋め488、FNV-1aチェックサム4を持ちます。数値はlittle endianです。連番・対象・会員・長さ・予約領域・制御文字・チェックサムを検証します。日時はこの記録には保存しません。既存AUDITへの表示統合は対象外です。

追記とディスク同期が成功してから応答し、書込み失敗後は掲示板操作と認証を停止します。途中レコードや不正な記録を検出した場合は元ファイルを修復・切り捨てず起動を拒否します。検証用サーバーは専用ディレクトリで動かし、常設サービスの置換はしていません。

## raw応答

- WITHDRAW: `WITHDRAW CONFIRM id` / `WITHDRAW SAVED id`。取り消し記事は `WITHDRAWN id PARENT parent`。一覧ではDEPTHも付きます。
- RETITLE: `RETITLED id`。
- FIND: `FIND scope author query`、行は `id board parent title`、`END NEXT cursor`。続きは `FINDFROM cursor scope author query`。
- SCAN: 通常のARTICLE応答を1件ずつ返し、空行またはCONTINUEで続行、最後に `SCAN END`。STOP時は現在の言語の中止文を返します。
- READGLOBAL id: 閲覧権限を確認して対象ボードへ移動し、ARTICLEまたは取り消し表示を返します。
- INFO: `INFO id title`、`DESCRIPTION text`、`END INFO`。
- PROFILE: `PROFILE id login`、`HANDLE text`、`BIO text`、`END PROFILE`。更新は `PROFILE SAVED`。
- PROFILES: `PROFILES query`、行は `id login handle`、`END NEXT cursor`。続きは `PROFILESFROM cursor query`。`PROFILEID id`でID指定閲覧も可能です。
