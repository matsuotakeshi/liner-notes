# Liner notes 0.74 変更・検証記録

基準は0.73（545af1e）。独立した作業ツリーで開発しました。
本番srv.ysni.orgのサービス・設定・データは変更していません。

## 追加内容

- Rocky Linux用RPM。本体・Web・リンクの分割、専用ユーザー、systemd、設定保持。
- Apache HTTPS経由で大容量を複数同時に送受信する再現可能な試験。
- Webの管理者専用リンク管理。状態確認、相手ごとの停止・再開・再試行。
- 署名付きチェックポイント、履歴の物理回収、別DBへ検証して取り込むスナップショット。
- 識別用の署名鍵を維持した通信専用TLS鍵の自動更新。
- 32件単位のメタデータ取得、本文を読まない変更判定、設定可能な巡回予算。

## 検証環境と確認済み結果

利用者指定のRocky Linux 10.2 x86_64、Python 3.12.15、systemd、SELinux Enforcing。
新規の検証データ・専用ユーザーを使用しました。

- RPM新規導入、0.1→0.2→0.3更新、独自設定・バナー・HELP・Webテンプレートと会員・記事の保持。
- 専用ユーザーで常駐起動、SIGKILL後の自動復旧、サービス再起動後のログイン・記事閲覧。
- 最終RPM 0.74-0.3で検証機を1回再起動し、BBS・Web・リンクの自動起動を確認。
  再起動前後の設定ハッシュ一致、会員・記事の保持、Web管理者権限、リンク管理操作を再確認。
  試験終了後は3サービスを停止・無効化し、RPM・設定・試験データを保存しています。
- Web追加RPMの常駐起動。ディストリビューション提供のaiohttp／cryptographyを使用。
- Apache HTTPS＋Web＋BBSで159,809,104バイト×4接続の同時送受信。
  4ファイルすべてのサイズとSHA-256が一致。合計アップロード3.50MiB/s、
  ダウンロード11.96MiB/s、転送中PINGの95%点約20ms、最大約56ms。
- 10,050記事・うち1,005件取り消し。旧イベント11,055件を回収し、新規DBへ取り込み。
  再送による重複0。メタデータ索引と署名付き末尾検証を含む版で処理約125秒、追加最大RSS約10.7MiB。
- 実BBSで、取り消し済み親記事への返信、新規参加後の題名変更、再送、巡回のまとめ読み。
- 実BBSの12,000記事のメタデータを376要求・約0.56秒で巡回。本文はこの巡回へ含めません。
- 一般ユーザーによる既存の掲示板・メール・保管庫・Door・Web・DB・COM・リンクの回帰。
  大規模起動試験では既存CIと同じ180秒の待ち時間を使用しました。
- FreeBSD 15.1の独立コピーでもWeb・Door・DB・COM・3ノードのスター／リング同期を検証。
  SQLiteが二重引用符を文字列として扱わない構成で見つかった状態記録SQLを修正しました。
  修正後のdaemon・保守試験も通過。10,050記事の整理・取り込みは約35秒、
  12,000記事のメタデータ巡回は376要求・約0.35秒でした。

## 検証の意味と境界

大容量試験は合成ファイルを使い、同一検証ホスト内のApacheを経由しました。
実インターネットの帯域・遅延、設置先Apacheの全設定、最大16接続×1GiBを保証する結果ではありません。
SELinuxは有効のままですが、BBS専用の新しいSELinux制約ポリシーを提供したわけではありません。
署名付き履歴の整理はリンクDBを対象とし、BBS本体の取り消し本文回収は外部管理ツールの担当です。
新規参加用スナップショットは全発信元の署名と許可を検証し、秘密鍵・会員・私信を含みません。
