# 親記事一覧のスレッド未読件数 — 第24段階

`N` または `NOTES` の親記事一覧に、スレッドごとの未読件数を表示します。ログイン中の会員の既読記録に基づき、親記事自身とすべての深さの返信を1記事ずつ数えます。

```text
1  話題の題名
    返信 2 件 / 最新 #3 / 2026-10-26T00:00:00Z / 未読: 3
```

非表示記事は未読件数から除外します。親記事自体が非表示の場合は従来の非表示行を維持し、件数や題名を追加しません。返信数・最新記事番号・更新日時の既存の意味は変更していません。

会員の未読ゼロは `未読: 0`、ゲストまたは会員機能を使わない構成は `未読: -` です。英語では `Unread: 数値` と表示します。他会員の既読記録は影響しません。現在ボードの閲覧権限は従来どおり確認します。

一覧表示や記事を読むだけでは既読にしません。SEEN/UNSEEN、投稿、非表示・復元は次回の一覧取得に反映されます。画面ページ送り中の取得済み一覧はその時点の件数を維持し、N/NOTESを再実行すると最新を取得します。PAGER ON/OFF、最大5件単位の取得と `+` による続き表示は従来どおりです。

## 通信と保存

rawのNOTES行は、題名の前に `unread=` フィールドを追加しました。固定形式を解析する外部クライアントは更新が必要です。

```text
NOTES 1
#1 replies=2 latest=3 updated=2026-10-26T00:00:00Z unread=3 話題の題名
END NEXT 0
```

ゲストのフィールド値は `unread=-` です。保存形式は変更していません。集計は共通ワーカーが行い、将来のCOM・Webでも同じ結果を利用できます。
