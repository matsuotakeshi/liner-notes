# RTBBS風コマンド整理 — Liner notes stage67

対象は通常のメニュー/Telnet操作です。旧RTBBS 5.3βbの MAINSYS.PAS、MAILSYS.PAS、FILESYS.PAS、EDITSYS.PAS、CHATSYS.PAS、PROFSYS.PAS、SYSOPCMD.PAS の実際の分岐を基準にしています。保存形式や会員番号を旧版へ戻す変更ではありません。

## 操作の原則

- 主画面、掲示板一覧、記事閲覧、メール、保管庫、個人設定、プロフィールで短縮キーを分けます。通常プロンプトのMAIN / BOARD / READ / INSTALL / PROFILEで現在の画面が分かります。
- `?`は現在画面の案内、`MENU`は主画面。`0`は戻る操作です。記事閲覧では一覧へ、掲示板一覧・個人設定・プロフィール・メール・保管庫では主画面へ戻ります。
- 主画面の`O`はY/N確認後に切断です。空入力は中止。明示的なQUITは確認なしです。接続を維持したログアウトは`LOGOUT`。`Q`も切断できますが、ページ停止・連続読み中では表示を中止する既存の意味を維持します。
- `MAIL`、`CHAT`、`TALK`、`VAULT`、`POST`、`READ`、`TREE`等の名前付きコマンドは維持します。メニューでは引数なしの`REGISTER`、`LOGIN`、`POST`、`REPLY`、`SEARCH`も必要項目の入力へ進めます。
- コマンドは大小文字を区別しません。本文、題名、ハンドル、検索語、パスワード等の入力内容は保持します。入力中は`/CANCEL`で中止できます。
- rawプロトコル、binary-v1、ファイル転送の通信形式は変更しません。

## メール・保管庫

メール一覧画面の`L`一覧（本文表示中のLは再表示、Pは前、Enterは次、Fは無停止）、`E`作成、`R`返信、`K`削除、番号指定、`0`終了を維持します。`N`は旧版に合わせて日付入力、`T`は最新から連続読みへ変更しました。次の未読は`MAIL NEXT`、最新1通だけなら`MAIL LATEST`です。

保管庫は`L`一覧、`U`登録、`D`取得、`B`一括選択メニュー、`N`日付指定、`I`ボード案内、`0`終了です。

- `FILEBOARD パス`で現在位置を選び、`U`は転送方式・説明（XMODEM/TEXTは名前・サイズも）を尋ねて現在位置へ登録します。
- `D`は番号を尋ねます。`D 番号`で取得を開始します。番号単独は選択画面を開き、表示・取得・バッチ追加へ進みます。`FILE 番号`は詳細表示です。
- `B`は追加・削除・ワイルドカード・一覧・クリア・送信の選択メニューです。ボード一覧は`FILEBOARDS`です。
- `I`は現在のファイルボードの案内です。カテゴリ抽出は`FILESIN`です。
- `U` / `D` / 番号指定は`PROTOCOL`で選んだ方式を使います。`ZUPLOAD`等のZ付きコマンドはZMODEM固定です。

掲示板・メール・保管庫の`N`で日付を空入力すると、現在ボードの記事 / 本人の受信メール / 現在のファイルボードと配下を巡回します。メニューでは最後の表示完了後に開始日時を自動保存。途中の中止では保存しません。CHECKMODE MANUALは明示CHECK DONE方式です。

## エディタ・設定・プロフィール

ベタエディタの`//`は即時送信をやめ、旧版に近い **W=書き込み、E=編集へ戻る、0=取り消し** の確認へ進みます。ラインエディタの`0`も同じ確認です。取り消しの`Q`も別名として残します。拡張操作の`.`は従来どおり即時確定、`/SAVE`は保存下書きです。rawモードの`//`は既存クライアントとの互換性を維持します。

`I`で入る個人設定は、P=パスワード、H=ハンドル、D=表示設定案内、1=エディタ、3=案内量、4=停止行数、0=戻るです。停止行数は0=無停止、5〜97。`LANG`や`PAGER SIZE`なども使えます。

プロフィールはL=一覧、P=会員指定、S=検索、W=長文自己紹介、E=項目番号を選ぶ編集画面、0=戻るです。名前付きコマンドによる項目変更・公開範囲設定には`PROFILESET` / `PROFILEVIS`等を使います。

## 揃えていない操作・残る差分

次は「操作が存在しないもの」「同等機能を別コマンドで提供するもの」「対話の細部を再現していないもの」を区別しています。

| RTBBS側の操作 | 現状・代替 | 差を残す理由 |
|---|---|---|
| 主画面Xのゲートウェイ | 未実装。Xは案内のみ | 以前の方針どおり対象外。独自BBS間リンク/FidoNetとも別機能 |
| SYSOPのDOSファイル操作・コンソールロック | BBS内には設けない | FreeBSD/daemon運用の管理手段へ分離 |
| 端末属性の旧ESCモード | 未実装。設定2は差分の案内 | DOS端末固有の属性を再現せず、UTF-8・Telnet・LANG・PAGERを使用 |
| `$`配下の旧SYSOPメニューのA/F/B/L/S | 権限付き操作案内まで。実行はAPPLICATIONS / APPROVE / DISCONNECT / SHUTDOWN等 | 現行の権限・対象番号・CONFIRMを明示する運用を維持 |
| ボード内`$`の番号式設定画面 | BOARDSET / BOARDOPTIONS / BOARDPASS等 | 階層・ACL・保存方式が異なるため現行引数形式を維持 |
| ファイルボードの`$`管理画面 | FILEBOARDSET / FILEOWNER / FILERENAME等 | 管理操作を名前付きコマンドで提供。旧対話画面は未再現 |
| プロフィールE | 項目番号式の編集画面と名前付き操作 | 現行仕様で確定。追加項目・公開範囲・他会員編集の権限を維持 |
| フォーラムの配置番号、`#nnn`移動 | BOARD 番号、FILEBOARDS、階層パス | 記事・ボード・ファイルの識別方法は旧データと互換ではない |
| 掲示板Lの全記事平面リスト | Lは親記事一覧。TREEで返信、LISTでも一覧取得可能 | HyperNotesの親記事・返信構造を維持 |
| 読書中Sの投稿者プロフィール直行 | Sで現在の記事投稿者を表示。PROFILEも利用可能 | 0.71で対応。公開範囲を維持 |
| 読書中のA/D | 最初の返信/親への対応あり。分岐全体はTREE | 旧版の単一の返信連鎖とHyperNotesの返信木は同一ではない |
| 新着確認 | 空入力で現在範囲を巡回し、表示完了時に日時更新 | 範囲別に保存。RAWではMANUALが既定 |
| 新着日付の表記 | YYYY-MM-DD、設定タイムゾーン基準 | 旧版の日付入力形式とは異なる |
| ファイル転送時の一連の質問、旧バッチ画面 | 方式・説明等の質問と一括選択メニュー、名前付き操作も維持 | コネクタ方式を維持。XMODEM/TEXTの受信は名前・サイズ等を明示する必要がある |
| 記事Eの投稿者指定 | 会員番号を入力 | 旧版のログインID指定とは入力形式が異なる |
| 主画面L/Uの公開範囲 | 自分の接続履歴、公開プロフィールが基本。全体ログは設定・権限に従う | 旧版の公開範囲へ自動で緩和しない |
| 主画面S/V/#の表示内容 | Liner notes案内/版情報/自分の会員状態 | DOS・モデムの回線速度等を同じ内容では表示しない |
| エディタ・読書の確認文、キー受付タイミング | 主要キーは対応。文言・範囲・制限は現行方式 | 完全な端末エミュレーションではない |

## Liner notes独自機能として名前付きで残すもの

- HyperNotes: TREE / PARENT / CHILD / NEXT / PREV、未読管理一式。
- 検索: SEARCH / FIND HERE・ALL・SUBTREE / SCAN、前回日時のCHECK。
- 投稿・編集: WITHDRAW / RETITLE / AUTHOR、/UNDO / /PREVIEW / /SAVE、DRAFT / RESUME。
- メール: MAIL SEARCH / DRAFT / RESUME / NOTIFY、/ATTACH、ZMAILUPLOADBATCH、ZMAILDOWNLOADALL等。
- 保管庫: FILEDESC / FILEDELETE / FILERENAME / FILESTATS、BATCH MATCH、ZRESUME / ZUPLOADBATCHRESUME等。
- 管理: SIGOPGROUP / BOARDGROUP / BOARDDELETEALL / MOVEBRANCH / CONNECTIONS / ANNOUNCE / DISCONNECT / SHUTDOWN等。
- 外部ゲーム: GAME / GAMESでゲーム一覧、番号で起動、終了後は一覧へ復帰。DOOR 番号も利用可能。
- OS側の保守: liner-notes-adminのbackup / verify / restore / compact。SQLiteはdb-migrate / db-backup / db-export / db-restore / db-compact。

## stage66以前からの更新

SQLite原本保存は明示設定時のみ有効。移行・復旧はSTAGE67.mdを参照してください。**メニューとHELPをバイナリと同時に更新してください。** portsの@sampleは編集済みファイルを保持するため、古いメニューの「M=メニュー」「E=保管庫」「O=ログアウト」等は自動で直りません。`share/liner-notes/menus/*.sample`、`help/*/*.sample`と比較して反映します。新しいサブメニューはboard-/reader-/settings-/profile-の各言語ファイルです。足りない場合は内蔵の案内を使います。

旧キーを使うスクリプトや操作マクロは、名前付きコマンドへ変更してください。例えばG→REGISTER、W→POST、M→MENU（旧メニュー表示の用途）、O→LOGOUT（接続維持の用途）、F→NEW（旧未読の用途）、保管庫B→FILEBOARDS、保管庫の番号詳細→FILE 番号です。

操作履歴の再表示は `AUDIT REFRESH`。現在の絞り込みを保って最新ページへ戻ります。`AUDIT ALL` は絞り込み解除です。旧Liner notesの `V` は、主画面では版の表示に変更しました。
