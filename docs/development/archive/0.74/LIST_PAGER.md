# 一覧の画面ページ送り — 第16段階

記事本文と同じ `PAGER ON/OFF` を、返信ツリー・検索結果・ベースノート・未読・記事一覧・ボード一覧・会員一覧・管理操作履歴にも適用します。保存済みの会員設定もそのまま使います。初期設定、手動サイズ、TelnetのNAWS、日英表示は [PAGER.md](PAGER.md) と共通です。

## 2種類の「続き」

- `[続:Enter/止:Q/OFF]>` が出ている間は、Enterで**取得済み一覧の残りの画面**を表示します。
- 通常の操作プロンプトへ戻ってから `+` を入力すると、**次の一覧データ**を取得します。

画面待ち中に `+` や記事番号を入力しても実行せず、画面操作の案内を再表示します。一覧を読み終えるかQで中止してから操作してください。従来の取得件数・検索の走査上限は変更しません。小さい画面では、1回に取得した一覧が複数画面に分かれます。

Qまたは/CANCELは取得済み一覧の未表示部分を破棄し、通常の操作プロンプトへ戻ります。その後の `+` は次の一覧データに進むため、中止した部分も読みたい場合はNOTES、TREE、SEARCHなどを再実行してください。記事番号・ボード番号・会員番号・履歴番号の意味は、最後に取得した一覧の種類に従います。

画面待ち中のOFFまたはPAGER OFFは残りをまとめて表示し、その接続のページ送りを無効にします。保存済み会員設定はPREFS SAVEするまで変更しません。

## 権限と状態

表示対象は保存ワーカーが権限確認を済ませた応答です。画面送りのために追加の記事読込みや既読更新は行いません。本文と同様、表示中の一覧は取得時のコピーです。後から非表示にした記事の題名などが、取得済み一覧から撤回されることはありません。記事番号を指定して新しく開く際は、その時点の権限と非表示状態を再確認します。

UIの一覧種類と次の取得位置は、画面断片とは独立して保持します。raw応答、コマンドの結果、認証案内、メニューそのものは今回の一覧分割の対象外です。保存形式やデータ変換は変更しません。会員停止などの接続失効では残りの表示内容も破棄します。
