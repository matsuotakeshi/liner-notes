# VS風端末UI

`vs` はPC-9801版1.31β6の公開操作資料を参照したLiner Notesの独立実装です。参照した版、原本のSHA-256、利用条件と操作の根拠は [VS_REFERENCE.md](VS_REFERENCE.md) に記録しています。rtbbs、mmm、mash、ktbbs、big-model、wani-bbs、net-cockに続く8番目の端末UIで、既存の8枠に収まります。UI追加時はアダプター配列、許可マスクと起動時の許可一覧を併せて確認してください。

## 操作

| 画面 | 主な操作 |
| --- | --- |
| 主画面 | `B` 掲示板、`F` 保管庫、`M` メール、`N` ニュース、`NA` 一気読み、`NF` ファイル、`P` ポインタ、`D` ダイレクト書き込み、`C` チャット、`U` 設定、`/T` 電報、`/W` 回線一覧、`H` HELP、`O` 終了 |
| 掲示板階層 | `#ID`・表示番号・ボード名、`.` 上位、`+` 現在階層、`*` 配下、`A ID ON\|OFF` 巡回対象 |
| 掲示板 | `L [ID]` 題名一覧、`L DATE 日付`、`L BY 投稿者`、`L TITLE 題名`、`L BASE`、`R [ID]` 本文、`W` 投稿 |
| 読書 | Enter／`B` 前後、`+`／`-` 方向、`S` 関連、`T` 関連先頭、`R` 返信、`P` プロフィール、`K` 取消確認、`Q` 復帰 |
| ニュース | Enter 逐次、`A` 連続、`S` 次のボード、関連連続時の `T` はベース参照、`Q` 中断、連続表示中は Ctrl-C などの入力で停止 |
| ポインタ | `P` メニューで `T` 先頭、`B` 最新、`D` 日付、`L` 前回ログイン、`#` 現在値。主画面・階層・掲示板から対象範囲を指定 |
| ダイレクト書き込み | `D` から `W` または `R`。一行入力の例は `D;W;#1;題名;Y`、`D;R;#1;12;題名;Y`、短縮形 `DW#1;題名;Y` |
| エディタ | `/ES`／`/POST`、`/ABT`／`/CAN`、`/CLR`／`/NEW`、`/L`、`/LN`、`/I:行`、`/O:行`、`/A`、`/D:行`、`/TITLE:題名`、`//` |
| メール | `R [ID]`、`L`、`W 会員ID`、`K`、`B` 添付、`GET`、`UPLOAD`、`SENT` |
| ファイル | `CD`・`.` 階層移動、`L` 一覧、`R ID` 詳細、`F` → `S 名前` 検索、`B` バッチ。転送は局で有効な方式を指定 |
| Liner Notes拡張 | `GAMES`、`TALK`、`TOPIC`、`DRAFT`、`MANAGE`、`UI` |

認証と設定の永続化は既存Coreを利用します。命令部分は大文字・小文字と全角英字を受け付けます。本文と引数の表記は維持します。直接書き込みの入力は1件の投稿準備に限定され、本文データは次の入力で受け付けます。ジャンプレス `J`／`DJ` は、ボード間の親子関係や可視性を変えずに拒否します。

## 記事表示とニュース

通常読書は記事番号順のフラット表示です。関連記事セレクタでは同じルートの記事を番号順に表示します。投稿・返信の保存と可視性の判定は共通Article Coreを使うため、既存HyperNotes表示でも同じ親子関係を参照できます。

ニュースの順序は `U` → `B` → `N NUMBER` または `N RELATED` で会員別に保存されます。初期値は番号連続です。関連連続はルート番号の昇順にグループを選び、各グループ内は記事番号の昇順です。記事本文の既読と、VSニュースの時刻ポインタは別々に更新します。ニュース完了時のみボード単位のポインタを前進させます。中断したボードは次回再表示される場合があります。巡回開始と同じ秒に登録された記事は次の巡回で対象になります。制御フロー中に許可の変更や保存失敗が発生した場合は、当該巡回を止めます。

VSの購読除外、順序設定、ボード別と全体のポインタは既存会員設定基盤の専用種別に保存します。記事と設定のためのスキーマ追加はありません。ボードACL、記事の有効な可視性、投稿時の認証世代は既存Coreで再検査します。電報は一覧表示時の接続世代と宛先を照合し、受信制限は共通の配送処理に従います。受信側がニュース・編集・転送・Doorなどを操作中は、同じ接続の認証世代に最大4件を保留します。受諾は既読を意味しません。受信可否は `U` → `T ON`／`T OFF` で設定できます。

## 互換範囲

ボード別の一行ボードとニュース統合は0.76の対象外とし、後続対応に回します。ジャンプレス、同報メール、旧クライアントの完全なマクロ互換、旧テンプレートと画面素材、プロフィールの新着一覧、多数のチャットルームと施錠、ファイルファインダの登録者・コメント検索、行装飾と位置揃えは未対応です。共通の一行会議とTOPICは独自拡張として利用できます。転送エンジンが受け付けない方式は拒否します。文字コードと制御シーケンスはLiner Notesの端末層の対応範囲に従います。

## 検証

`make test-vs-input` は正規化と直接書き込みの構文、`make test-article-core` はグループと可視性、`make test-vs` は実Telnetでの投稿、両巡回モード、中断と再起動、MASHでの返信の参照を確認します。既存SSH受入試験にも選択・閲覧・RTBBSへの復帰を追加しています。

開発環境のGCCで、変更したCモジュールの厳格ビルド、VS入力、Article Core、Member Core、SQLite設定保存、UI寿命、依存境界を確認しました。統合マニュアルは生成・ZIP化・リンク・検索チェックを通過しました。POSIXバイナリを用いる実接続テストとOS別パッケージ検証の結果はGitHub Actionsで確認します。
