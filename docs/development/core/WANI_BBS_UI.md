# WANI-BBS風端末UI

参照資料と版差は [WANI-BBSの操作資料](WANI_BBS_REFERENCE.md) に記録した。Windows 2.0β7のコマンド定義、利用者・SYSOP・HELP文書を優先し、DOS/V 1.31の対応箇所を補助資料にした。画面とコードは独自に作成した。

## アダプターと保存

`wani-bbs` は独立した SessionUiAdapter で、MMM系の型付き要求、ログイン、エディタ、転送およびサービス結果の描画を共有する。ディレクトリ、操作中の画面、ページ一覧、巡回対象、編集中の一時ファイルは接続に属する。UIの切替許可、認証、Board/Vault/MailのACL、Door認証は既存の実装を使用する。

ボード設定は `wani_board_views`、購読は `wani_subscriptions`。既定値にはボードID 0を使い、未指定はマルチノーツ。記事テーブルの変換を伴わない。Flatは公開可視記事のID順、マルチノーツはルート記事の索引・表紙と配下返信のID順。ページ選択時は表示したIDとノートルートを再検証する。投稿先は通常板では閲覧中の記事、マルチノーツではノートのルート。監査・非表示制御・リンクの既存規則を継承する。

WANI-BBSのシーケンサは会員設定の種別4に保持し、MMMの種別3から分離する。購読リストはMMMおよびBIG-Modelとは別。新着選択は開始時刻で上限を固定する。一覧表示で既読を一括変更しない。記事本文の閲覧で共通の既読を更新する。巡回終了キーの更新対象はWANI用の基準時刻。

TOPICは共通の会議で使う接続照合と文字検証および所有スレッドを利用する。データは `topic_lines` と `topic_read` に保存する。基準は会員別のID、削除は本人か管理者。削除済みの番号は再利用せず、本文と表示名を消去する。通常の未読表示が出力キューに載った時点で既読を進める。履歴と逆順表示では既読を変更しない。CHAT、個別トーク、共通TALKとデータを分ける。追加テーブルはfeaturesの既存バックアップ・復元対象。

## コマンドと差異

操作一覧は [統合マニュアル](../../manual/personal-settings.md#wani-bbs-ui) を参照。端末の日本語処理と接続方式にはLiner Notesの既存の対応範囲を適用する。

- ノート閉鎖、開放、作成者専用の制限は保留。ローカル投稿とリンク受信で同じ判定が可能になるまでUI側にも制限キーを置かない。
- 記事の訂正は題名に対応。本文の上書きは保存・監査・転送の整合性を保つCore APIが必要。通常会員による `D` と `e` は当該ボードの最後の本人記事に限定し、確定時にCoreで検査する。
- `fastread`、`fast`、`cont` は通常掲示板の新着一覧へ入る。DOS/V版の無停止連続出力や旧巡回クライアントの互換性は未検証。巡回対象は一度に64ボードまで。対象過多はエラーになる。
- 受信箱内の返信・親メール・消去・取込は共通のMail Coreを利用。旧バイナリメール、複数宛先、配達確認、WHIP・UUCPアドレスは未対応。Liner Notesの添付は保管庫と別権限の共有機能を利用する。
- エディタは `E 範囲 旧 新` のリテラル置換。パーソナルファイルは最大10KiB。旧 `directedit`、切断後の自動メール送信、独自制御キー、ISH、旧管理ユーティリティ、原作のゲームは未対応。下書きと既存のDoorはLiner Notes拡張。
- TOPICの投稿はUTF-8で最大512バイト。固定件数での旧式自動消去は適用しない。登録はログイン済み会員に限定し、予約ゲストは既存の会議アクセス規則に従い拒否する。

## 検証

`make test-wani-bbs` はコマンド・範囲・ワイルドカードの単体試験と、Telnetでの表示形式・返信・ACL・個人ファイル・TOPIC・Door・再起動を検証する。`make test-conference-core` はTOPICの権限、既読、削除後のID、保存失敗を検証する。既存の会員設定、記事、Session UI、Canonical manualの回帰も適用する。
