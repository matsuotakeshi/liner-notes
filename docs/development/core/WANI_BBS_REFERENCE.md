# WANI-BBSの操作資料

主資料はWindows版2.0β7の `wani20b7.zip`。DOS/V版1.31の `waniv131.lzh` を補助資料にした。両方とも保管済みの配布物から文書・定義だけを隔離展開し、CP932として読んだ。ホスト本体は実行していない。`MANUAL.TXT` はWindows版のHTM・DEF、DOS/V版のMAN・DEFの単独配布や改変を許可している。実装と案内文は独自に記述し、原典ファイルは配布物に含めない。

| 対象 | 原典の確認内容 | Liner Notesでの対応方針 |
|---|---|---|
| 認証とディレクトリ | USER 1・3章、ALIAS.DEFの `b/p/s/g`、COMMAND.DEFの `cd` | Session認証を使用。仮想ディレクトリに限定し、番号や名前から認可済みボードを選ぶ。 |
| 通常掲示板 | USER 5章。番号、Enter、`.`、`=`、`*`、`B`、`W`、`Q/Z`。リストの範囲指定あり。 | 共通フラットページと記事IDを使用。単独の新規投稿と返信を区別する。 |
| マルチノーツ | USER 6・7章。インデックスの番号は表紙、`.` はページ一覧。ページの `W` はノートへの追記。 | ルートを表紙とし、子孫を深さにかかわらず番号順で表示。追記先はルート。 |
| 表示形式・閉鎖 | SYSOP 3章。ボードの `M`、ノートの開放・閉鎖と作成者専用の扱いを確認。 | 表示形式はWANI-BBSの設定。既存記事を変換しない。返信制限の実装は共通Coreによる確定時判定が条件。 |
| 巡回 | USER 3・5〜7章、HELP/OPEN.TXT。 `-f` は購読、`-s` は新着、`-i` は索引、`-x` は新着または索引。 `-f` と明示名は排他。 | 他のUIの巡回設定と分け、見出しだけの表示では既読にしない。 `Q/q/Z/z` の区別を保持する。 |
| 版差・シーケンサ | USER 3章、COMMAND.DEF、Change.txtとDOS/V USER.MAN 3章。DOS/V版の `CONT` は一時停止を省く連続読み出し。Windows版のコマンド定義には `fastread`、`seqset` がある。 | TCPでの厳密な停止タイミングと旧セーブ形式の互換は未確認。基準値は現行の会員設定で扱う。 |
| エディタ・一時ファイル | USER 2・4章、BBSREFのdirectedit。 `S` は一時ファイル保存、`R/Y` は読み込み、`K` は消去、本文の単独 `.` で編集に戻る。 | 既存Editor Coreと接続内バッファを利用。保存は置換。旧端末制御の再現範囲は実装文書で記録する。 |
| TOPIC | HELP/TOPIC.TXTとALIAS.DEFの `rtopic/rhello`。未読、最後・全件既読、範囲、逆順、本人の削除。 | 公開チャット、私信、通常の一行会議と表示・既読位置を分ける。 |
| 郵便受け・プログラム | USER 8・9章とHELP/MAIL、CHECK。旧バイナリメール・配達確認の記載あり。 | Mail/Vault Coreと既存転送。WHIP、UUCP、ISHとの互換は対象外。 |
| 会員情報、チャット、ゲーム | USER 10〜12章、DEF群。 | 局の認証・ACL、プロフィール、Chat/Doorを利用。旧ゲームは移植しない。 |
| エイリアス・管理 | COMMAND.DEF、ALIAS.DEF、SYSOP。定義にはホストOS操作へつながる別名もある。 | 固定のBBS操作だけを提供し、OSファイル操作やシェル呼び出しを扱わない。 |
