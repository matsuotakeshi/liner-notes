## 利用条件

PC-98版の `VSD.LZH` 内 `VS.DOC` の解析・改造・著作権の節を確認した。作者はリバースエンジニアリング、逆コンパイル・逆アセンブル等と本体の改造を禁止し、配布ファイルの著作権を保持する。転載にはアーカイブを変更しないことと必要経費を超える金銭を要求しないことが条件となる。`VSMHK.DOC` の著作権・転載条件はVSに準じる。本体・リソースを開かず、公開文書の仕様に基づいて新しく実装する。原典・展開物・表示文・素材はコミットおよび配布に含めない。

## 操作と採用する境界

| 根拠 | 確認した仕様 | Liner Notesの対応 |
|---|---|---|
| `USER.DOC` 入力方式、メイン、メッセージボード | 1文字中心。英字の大文字小文字、全角半角。メッセージツリー・ボード・一行ボードを区別。 | コマンドだけを正規化。階層とIDは共通Catalog・Article Core。 |
| `USER.DOC` リード／サーチ、`READ_S`・`SEARCH_S` | 直接番号なら正順、Enterだけなら最新から逆順。関連の先頭と前後、通常返信。 | 平面一覧と同じルートに属する記事のページを使用。 |
| `USER.DOC` N・NA・P、設定、`NEWS_S`・`NEWS_SS`・`POINTER` | 番号連続、関連連続。関連連続のTはベース。通常のリードではニュース位置を更新しない。 | 番号は記事ID順、関連はルートID順・各グループ内記事ID順。文書にない同順位の扱いは独自規則。 |
| `USER.DOC` 入力方式、ダイレクト書込、`DIRECT`・`EDIT` | セミコロンと既知の英字列の省略、W・Rの確認後に本文。編集制御はスラッシュ付き。 | 入力全体を検証できる形のW/R連続入力から対応し、共通Editorと投稿認可を利用。 |
| `USER.DOC` メール・ファイル・チャット、`MAIL`・`FILE_B`・`CHAT` | メール、ファイルファインダとプロトコル指定、電報、チャット。 | 私信・保管庫・公開チャット・電報を各Coreに委譲。 |
| `USER.DOC` 一行ボード・`SYSOP.DOC`・`HOST.DOC` | 一行ボードは通常ボードとは別種別で、短文の件数と巡回を管理。管理への入口は権限に依存。 | 一行会議やTOPICと無条件に統合しない。専用ボードの互換は保留。 |
| DOS/V版 `USER.DOC`、変更キット `MAIN`・`MESS_B`・`MESS_T`・`USER_B` | 操作の補助資料。外部HELPは1.30の画面構成を示す。 | 挙動の根拠はPC-98版の文書を優先し、新しいメニュー文言を作成する。 |

ジャンプレスの `J`／`DJ` は拒否する。通常返信と所属ボードを固定した既存データ構造を維持し、別ボードへ元記事の情報を複製しない。
