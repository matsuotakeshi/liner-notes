# 確認範囲と残る確認事項

## 公開前・公開後の確認

- ブラウザー目視検査は未完了。アプリ内ブラウザーはローカル接続に失敗し、通常ブラウザーは操作ツールが現在URLを確定できず停止した。検索ロジック、HTML構造、参照先、ファイル一致の自動検査とは別に記録する。
- 公開サイトの更新は設置者が行う。アップロード後のHTTPS、Apacheの任意301設定、キャッシュ更新、実URLでの検索・旧URL移動は未検証。
- オフライン版は全ファイルと検索データを同梱しfetchを使わない。各利用者のブラウザーでfile://表示が禁止されている場合のポリシー解除は扱わない。

## 意図的な対象境界

- 日本語の統合本文と英語の入口を用意した。本文全体の英訳は今回の対象外で、英語版完成とは表示しない。
- StarRoute Tradersの現行ゲーム版固有の初期宇宙作成・更新コマンドは、このBBSマニュアルから推測しない。汎用Door接続・既存データ維持・運用境界を説明し、ゲーム側の該当版手順を併用する。
- 実モデム、Solaris、未検証Linux、最大上限を組み合わせた長期運用の新しい検証結果はない。使用可能な検証機の存在を移植完了とは扱わない。
- 既存の0.74リリースtar/pkg/RPMは変更しない。その同梱文書が新しい公開マニュアルに自動交換されるわけではない。次回のアプリ配布では新しい正本を同梱する。
- 既存の実行時HELPで見つけた古い説明はソース側で6ファイル訂正したが、稼働中BBSには適用しない。次回のアプリ更新時に編集済みHELPと比較して反映する。

## 再発防止

`docs/CONTRIBUTING.md` とAGENTS.mdを今後の文書更新規則とする。機能別原稿・設定・権限・制限を更新し、短い変更記録をCHANGELOGへ書く。開発報告を公開原稿へ追加しない。追加原稿、根拠変更、旧URL対応、内部リンク、検索対象、原本一致をCIで検査する。
