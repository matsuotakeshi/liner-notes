Board administration
Withdrawals and hides conceal all descendants on every board; IDs and parent links remain. Receiving administrators/SIGOPs use HIDE locally; WITHDRAW is restricted to the origin BBS. RESTORE never reverses an origin withdrawal.
BOARDINFO id / BOARDSET id|parent|read|write|title|description
BOARDOPTIONS id BOARD|MENU order article-limit body-byte-limit access-log-limit
BOARDPASS id / BOARDPASS id NONE CONFIRM / INFOEDIT id
SIGOP board member|NONE / SIGOPS
SIGOPGROUP board group: administrator records a board ACL group; 0 clears its records
GROUP/UNGROUP authority uses current SIGOP scope and board ACLs, not this record alone.
BOARDGROUP board old-group new-group CONFIRM: administrator migrates this ACL and global memberships
Other board ACLs stay unchanged. Other connections must log in again.
BOARDGUEST board ON|OFF
WITHDRAW article CONFIRM: author, administrator or inherited SIGOP
HIDE / RESTORE / INSPECT article: moderation distinct from withdrawal
RETITLE article title / AUTHOR article member CONFIRM
MOVE root destination CONFIRM / MOVEBRANCH article destination CONFIRM
BOARDDELETE board CONFIRM / BOARDDELETEALL board CASCADE CONFIRM
BOARDLOG / BOARDACCESS board / AUDIT ARTICLE article
