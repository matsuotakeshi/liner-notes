Language, paging and preferences
LANG ja / LANG en selects Japanese or English.
PAGER ON / PAGER OFF controls screen paging (initially OFF).
While paging: Enter continues, Q closes the display, OFF flushes the rest.
Closing help preserves article selection and result-page position.
PAGER SIZE columns rows sets dimensions; Telnet also supports NAWS.
PREFS summarizes saved settings. PREFS SAVE stores language, paging, editor type, line numbers, transfer protocol and screen dimensions.
PREFS LOAD reloads them. Login restores them too.
RAW selects protocol output; MENU returns to menus. At the main prompt O/Q asks for confirmation; QUIT disconnects immediately.
Use D in Settings to inspect all current values.

MENUMODE BEGINNER / STANDARD / EXPERT: home menu always / initially / explicitly; saved per account.
LOGOUT saves settings and returns to guest; QUIT saves and disconnects. Network disconnects also queue a save; process failure or revocation can prevent it.
GAME / GAMES opens the game menu. Enter a number to play; exit returns to the game list. Enter/L relists; 0 returns to main. DOOR id also starts a game directly.
The game list requires login and shows only games allowed for your current member level.

D in Settings displays actual language, editor, menu verbosity, paging, screen dimensions, timezone and transfer protocol. S reads external sysinfo.txt; V shows version. O/Q ask Y/N; QUIT is immediate. goodbye.txt is displayed on exit.

Line numbering (editor M / /M) and PROTOCOL are included in PREFS SAVE/LOAD, login restoration and normal disconnect saving. Abrupt process failure or revoked credentials can prevent a save.
UI lists the active UI, station policy and permitted profiles. UI name selects a permitted UI; UI RESET returns to the station default and clears your saved preference. Members save selections immediately; guests use them for this connection only. Switch at the main menu after finishing editing, transfers, chat or games. Only RTBBS is currently installed; RAW is not a separate UI.

UI shows available profiles. UI mash selects MASH when the station permits it. The default is RTBBS unless configured otherwise. In MASH, log in, use 9 for the guide, cmdlst for commands and COMMAND -? for syntax.
UI ktbbs selects the KTBBS profile when the station allows it. At MAIN, ? displays the bilingual KTBBS guide. R opens board selection, E opens the posting menu, and ! opens Liner Notes extensions.
